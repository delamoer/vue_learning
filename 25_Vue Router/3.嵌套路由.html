Vue Router · 嵌套路由

25-3  |  children 配置 / 嵌套 router-view / 默认子路由 / 多级路由

第一节

为什么需要嵌套路由

真实应用中，界面通常是多层嵌套的。例如：用户中心页面有固定的侧边栏，但中间内容区根据不同子菜单切换。

【界面结构示意】 ┌─────────────────────────────────────────┐ │ 顶部导航 NavBar（每个页面都有） │ ├──────────┬──────────────────────────────┤ │ │ │ │ 左侧 │ /user/profile → 个人资料 │ │ 侧边栏 │ /user/orders → 订单列表 │ │ │ /user/favs → 我的收藏 │ │ │ │ └──────────┴──────────────────────────────┘

这里需要两层 <router-view>：

  • ① 最外层：在 App.vue 里，渲染"哪个一级页面"（Home / User / Admin...）
  • ② 内层：在 User.vue 里，渲染"用户中心的哪个子页面"
第二节

children 配置

路由配置：用 children 定义子路由
const router = new VueRouter({ routes: [ { path: '/user', name: 'user', component: User, // User 模板里要有 <router-view> children: [ // ★ 子路由的 path 不加 /，最终路径是 /user/profile { path: 'profile', name: 'user-profile', component: UserProfile }, { path: 'orders', name: 'user-orders', component: UserOrders }, { path: 'favs', name: 'user-favs', component: UserFavs }, // 访问 /user 时显示的默认子页面（path 为空） { path: '', redirect: 'profile' }, // 子路由也可以有动态段 { path: 'order/:orderId', name: 'order-detail', component: OrderDetail }, ] } ] })
⚠️ 子路由 path 的斜杠规则：
path: 'profile' → 最终路径是 /user/profile（不加 /，追加到父路径）
path: '/profile' → 最终路径是 /profile（加了 /，从根路径开始，通常不这样写）
父组件模板：必须包含 <router-view>
<!-- User.vue / User 组件的模板 --> const User = { template: ` <div class="user-layout"> <h2>用户中心</h2> <!-- 左侧导航 --> <nav> <router-link :to="{ name: 'user-profile' }">个人资料</router-link> <router-link :to="{ name: 'user-orders' }">我的订单</router-link> <router-link :to="{ name: 'user-favs' }">我的收藏</router-link> </nav> <!-- ★ 子路由渲染在这里，而不是 App 根组件的 router-view --> <router-view></router-view> </div> ` }
第三节

路由层级与 router-view 的对应关系

URL: /user/profile App.vue └── <router-view> ← 渲染一级路由：User 组件 └── User.vue └── <router-view> ← 渲染二级路由：UserProfile 组件 └── UserProfile.vue URL: /user/order/88 App.vue └── <router-view> ← 渲染：User 组件 └── User.vue └── <router-view> ← 渲染：OrderDetail 组件（orderId=88） └── OrderDetail.vue
📌 关键规则：有几层嵌套路由，就需要几层 <router-view>。每一层 router-view 只展示它所在层级的路由对应的组件。
三级路由示例
routes: [ { path: '/admin', component: Admin, // Admin.vue 里有 <router-view> children: [ { path: 'users', component: AdminUsers, // AdminUsers.vue 里也有 <router-view> children: [ { path: ':id', component: AdminUserDetail } // 最终路径：/admin/users/42 ] } ] } ]
第四节

命名视图（同级多个 router-view）

有时候需要在同一级同时渲染多个组件，比如"主内容区 + 侧边栏"。这时可以给 <router-view> 命名。

模板
<!-- App.vue / 根模板 --> <router-view></router-view> <!-- 名字是 default --> <router-view name="sidebar"></router-view> <!-- 命名视图 -->
路由配置：components（注意是复数）
const router = new VueRouter({ routes: [ { path: '/', components: { // ← 注意是 components 复数！ default: Home, // 渲染到没有 name 的 router-view sidebar: Sidebar // 渲染到 name="sidebar" 的 router-view } }, { path: '/about', components: { default: About, sidebar: AboutSidebar } } ] })
✅ 一般项目较少用命名视图。最常见的使用场景是"后台管理系统"布局，顶部导航 + 侧边栏 + 主内容区同时需要根据路由切换的情况。
第五节

完整可运行 Demo

<!DOCTYPE html> <html><head><title>嵌套路由 Demo</title> <style> body { font-family: sans-serif; max-width: 700px; margin: 40px auto; } nav a { margin: 0 8px; color: #666; text-decoration: none; } .router-link-exact-active { color: #6366f1; font-weight: bold; } .layout { display: flex; gap: 20px; margin-top: 16px; } .sidebar { width: 140px; border-right: 1px solid #eee; padding-right: 16px; } .sidebar a { display: block; margin: 8px 0; } .content { flex: 1; padding: 16px; border: 1px solid #eee; border-radius: 8px; } </style></head> <body> <div id="app"> <nav> <router-link to="/" exact>首页</router-link> <router-link to="/user">用户中心</router-link> </nav> <router-view></router-view> <!-- 一级路由出口 --> </div> <script src="../js/vue.js"></script> <script src="https://unpkg.com/vue-router@3.6.5/dist/vue-router.js"></script> <script> const Home = { template: '<div style="padding:16px"><h3>🏠 首页</h3></div>' } const Profile = { template: '<div><h4>👤 个人资料</h4><p>姓名：张三，邮箱：zhang@example.com</p></div>' } const Orders = { template: '<div><h4>📦 我的订单</h4><p>共 3 个订单</p></div>' } const Favs = { template: '<div><h4>❤️ 我的收藏</h4><p>共 12 个收藏</p></div>' } const User = { template: `<div class="layout"> <div class="sidebar"> <strong>用户中心</strong> <router-link to="/user/profile">个人资料</router-link> <router-link to="/user/orders">我的订单</router-link> <router-link to="/user/favs">我的收藏</router-link> </div> <div class="content"> <router-view></router-view> <!-- 二级路由出口 --> </div> </div>` } const router = new VueRouter({ routes: [ { path: '/', component: Home }, { path: '/user', component: User, children: [ { path: '', redirect: 'profile' }, // /user → /user/profile { path: 'profile', component: Profile }, { path: 'orders', component: Orders }, { path: 'favs', component: Favs }, ] } ] }) new Vue({ el: '#app', router }) </script> </body></html>
