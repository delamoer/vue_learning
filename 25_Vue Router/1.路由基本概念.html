第一节

什么是 SPA？什么是前端路由？

传统多页应用 MPA vs 单页应用 SPA
📄 MPA — 多页应用（传统方式）

每次跳转页面，浏览器都向服务器请求一个完整的 HTML 文件。

点击"关于我们" → 浏览器发请求 → 服务器返回 about.html → 整页刷新重新渲染。

缺点：每次都有白屏闪烁，体验差；服务器压力大。

⚡ SPA — 单页应用（现代方式）

整个应用只有一个 HTML 文件，页面切换时不刷新，只替换其中的内容区域。

点击"关于我们" → JS 拦截，动态替换内容区的组件 → 地址栏变化但页面不刷新。

优点：无白屏、体验流畅；组件复用、数据共享更方便。

前端路由的本质

前端路由解决的核心问题：URL 变化时，显示哪个组件？

// 路由就是一张"地址 → 组件"的映射表 URL / → 显示 Home 组件 URL /about → 显示 About 组件 URL /user/42 → 显示 UserDetail 组件（id=42） URL /404 → 显示 NotFound 组件
Vue Router 是什么

Vue Router 是 Vue 官方的路由库，专门为 SPA 设计。它做了两件事：

  • ① 监听 URL 变化（hash 变化 或 history pushState）
  • ② 根据路由表，渲染对应的 Vue 组件到 <router-view> 占位符处
📌 Vue 2 对应 Vue Router 3.x，Vue 3 对应 Vue Router 4.x。本章使用 Vue Router 3。
第二节

Vue Router 的基本配置

安装（在 SFC 项目中）
# Vue CLI 项目中安装 Vue Router 3 npm install vue-router@3 # 或一开始创建项目时选择包含 Router vue create my-app # 然后手动选中 Router 选项
在 HTML 文件中引入（CDN）
<!-- 必须先引入 Vue，再引入 Vue Router --> <script src="../js/vue.js"></script> <script src="https://unpkg.com/vue-router@3.6.5/dist/vue-router.js"></script> <!-- 引入后，VueRouter 自动注册为全局插件 -->
三步配置路由
// ① 定义路由组件（每个路由对应一个组件） const Home = { template: `<div> <h2>首页</h2> <p>欢迎来到首页</p> </div>` } const About = { template: `<div><h2>关于我们</h2></div>` } // ② 创建路由器实例，配置路由规则 const router = new VueRouter({ routes: [ { path: '/', component: Home }, // / 显示 Home { path: '/about', component: About }, // /about 显示 About ] }) // ③ 将路由器挂载到 Vue 根实例 new Vue({ el: '#app', router, // ← 挂载路由器（ES6 简写，等于 router: router） })
✅ 挂载路由器后，每个 Vue 组件实例都会自动拥有两个属性：
  • this.$route：当前路由信息（path、params、query 等）
  • this.$router：路由器实例（用于编程式导航，push、replace 等）
第三节

<router-link> 和 <router-view>

router-view — 路由出口

<router-view> 是一个占位符，当前路由匹配到的组件会在这里渲染。

<div id="app"> <!-- 导航区 --> <nav> <router-link to="/">首页</router-link> <router-link to="/about">关于</router-link> </nav> <!-- 内容区：路由匹配到的组件渲染在这里 --> <router-view></router-view> </div>
router-link — 声明式导航

<router-link> 会渲染成 <a> 标签，但它不会触发页面刷新，而是通过路由器切换组件。

<!-- 基本用法 --> <router-link to="/about">关于我们</router-link> <!-- 渲染结果（浏览器中）--> <a href="#/about">关于我们</a> <!-- hash 模式 --> <!-- 对象写法（推荐），便于后续扩展 --> <router-link :to="{ path: '/about' }">关于我们</router-link> <!-- 用命名路由（推荐，路由改名时只改一处）--> <router-link :to="{ name: 'about' }">关于我们</router-link>
router-link 的 active class（高亮当前路由）

router-link 被激活时会自动加两个 class，可以用来实现导航高亮：

/* 模糊匹配激活（/about 时，/ 也会激活） */ .router-link-active { color: #6366f1; } /* 精确匹配激活（只有完全匹配时才激活，推荐用于首页链接） */ .router-link-exact-active { font-weight: bold; border-bottom: 2px solid #6366f1; } <!-- 精确匹配用法 --> <router-link to="/" exact>首页</router-link> <!-- 自定义 active class 名（避免与其他 class 冲突） --> new VueRouter({ linkActiveClass: 'nav-active', // 全局配置 linkExactActiveClass: 'nav-exact', routes: [...] })
router-link 的 tag 属性（渲染成其他标签）
<!-- 默认渲染成 <a>，可以改成其他标签 --> <router-link to="/home" tag="li">首页</router-link> <!-- 渲染为 <li>首页</li>，但点击时仍然触发路由跳转 --> <!-- replace 属性：跳转后不留历史记录（不能后退） --> <router-link to="/home" replace>首页</router-link>
第四节

命名路由与重定向

命名路由（name）

给路由配置一个名字，导航时用 name 代替 path，路径变化时不用改导航代码。

const router = new VueRouter({ routes: [ { path: '/user/profile', name: 'user-profile', // ← 给路由命名 component: UserProfile } ] }) <!-- 用命名路由跳转 --> <router-link :to="{ name: 'user-profile' }">用户主页</router-link> // 编程式导航也用 name this.$router.push({ name: 'user-profile' })
重定向（redirect）
const router = new VueRouter({ routes: [ // 访问 / 自动跳转到 /home { path: '/', redirect: '/home' }, { path: '/home', component: Home }, // 用命名路由重定向 { path: '/', redirect: { name: 'home' } }, // 动态重定向（函数写法，根据条件决定跳转目标） { path: '/search', redirect: to => { // to 是目标路由对象 return { path: '/results', query: { q: to.query.keyword } } } }, // 捕获所有未匹配路由（404 页面），必须放在最后 { path: '*', component: NotFound } ] })
别名（alias）
// 访问 /home 和访问 /index 效果一样，但地址栏不变 { path: '/home', component: Home, alias: '/index' } // 区别：redirect 会改变地址栏；alias 不会改变地址栏

第六节

路由相关 API 速查

属性 / 方法说明示例
$route.path当前路由的路径字符串"/about"
$route.name当前路由的名称"about"
$route.params路径参数对象（/user/:id）{ id: "42" }
$route.query查询参数对象（?key=val）{ tab: "2" }
$route.hashURL 中的 hash（#xxx）"#section1"
$route.fullPath完整 URL（含 query 和 hash）"/user?id=1#bio"
$route.matched当前路由匹配到的所有路由记录数组用于面包屑导航
$router.push()导航到新路由（有历史记录）this.$router.push('/about')
$router.replace()导航到新路由（无历史记录）this.$router.replace('/login')
$router.go(n)前进/后退 n 步this.$router.go(-1)
⚠️ $route vs $router 容易混淆：
$route（没有r）= 当前路由信息（只读，包含 path、params、query 等）
$router（有r）= 路由器实例（可以调用方法，如 push、replace）
