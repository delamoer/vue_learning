## 💡 核心知识点

### 过渡的 6 个类名

```
进入过程：
┌─────────────────────────────────────┐
│  插入前    一帧后     过渡完成         │
│  ↓         ↓         ↓              │
│  enter  → enter-to                 │
│  enter-active ─────────→ 移除       │
└─────────────────────────────────────┘

离开过程：
┌─────────────────────────────────────┐
│  触发前    一帧后     过渡完成         │
│  ↓         ↓         ↓              │
│  leave  → leave-to → 移除元素       │
│  leave-active ─────────→ 移除       │
└─────────────────────────────────────┘
```

### CSS 示例模板

```css
/* 基础淡入淡出 */
.fade-enter-active, .fade-leave-active {
    transition: opacity 0.5s;
}
.fade-enter, .fade-leave-to {
    opacity: 0;
}

/* 滑动 + 淡入 */
.slide-enter-active, .slide-leave-active {
    transition: all 0.5s;
}
.slide-enter {
    transform: translateX(-100px);
    opacity: 0;
}
.slide-leave-to {
    transform: translateX(100px);
    opacity: 0;
}

/* CSS 动画 */
.bounce-enter-active {
    animation: bounce-in 0.5s;
}
@keyframes bounce-in {
    0% { transform: scale(0); }
    50% { transform: scale(1.2); }
    100% { transform: scale(1); }
}
```

### 列表过渡要点

```html
<!-- 必须有 tag 和 key -->
<transition-group name="list" tag="div">
    <div v-for="item in items" :key="item.id">
        {{ item.name }}
    </div>
</transition-group>
```

```css
/* 进入/离开 */
.list-enter-active, .list-leave-active {
    transition: all 0.5s;
}
.list-enter, .list-leave-to {
    opacity: 0;
    transform: translateY(30px);
}

/* 移动过渡（关键！） */
.list-move {
    transition: transform 0.5s;
}
```

## ⚠️ 常见陷阱

### 1. 多元素过渡忘记 key
```html
<!-- ❌ 错误：没有 key，无法区分元素 -->
<transition name="fade">
    <div v-if="show">A</div>
    <div v-else>B</div>
</transition>

<!-- ✅ 正确：添加唯一 key -->
<transition name="fade" mode="out-in">
    <div v-if="show" key="a">A</div>
    <div v-else key="b">B</div>
</transition>
```

### 2. transition-group 子元素没有 key
```html
<!-- ❌ 错误：列表项没有 key -->
<transition-group name="list">
    <div v-for="item in items">{{ item }}</div>
</transition-group>

<!-- ✅ 正确：必须有 key -->
<transition-group name="list">
    <div v-for="item in items" :key="item.id">{{ item }}</div>
</transition-group>
```

### 3. JS 钩子忘记调用 done
```javascript
// ❌ 错误：没有调用 done，过渡卡住
enter(el, done) {
    el.style.opacity = '1';
    // 忘记调用 done()
}

// ✅ 正确：必须调用 done
enter(el, done) {
    el.style.opacity = '1';
    setTimeout(done, 500);  // 动画完成后调用
}
```

### 4. v-show 无过渡效果
```html
<!-- ❌ 错误：v-show 第一次不触发过渡 -->
<transition name="fade">
    <div v-show="show">内容</div>
</transition>

<!-- ✅ 方案1：使用 v-if -->
<transition name="fade">
    <div v-if="show">内容</div>
</transition>

<!-- ✅ 方案2：使用 appear -->
<transition name="fade" appear>
    <div v-show="show">内容</div>
</transition>
```

### 5. 列表移动过渡失效
```css
/* ❌ 错误：使用 display: inline */
.list-item {
    display: inline;  /* 移动过渡不生效 */
}

/* ✅ 正确：使用 inline-block 或 block */
.list-item {
    display: inline-block;
}
```

## 🚀 性能优化

### 优先使用的 CSS 属性
```css
/* ✅ 性能好：GPU 加速 */
transform: translate(x, y);
transform: scale(x, y);
transform: rotate(deg);
opacity: 0-1;

/* ❌ 性能差：触发重排 */
left: 100px;
top: 100px;
width: 200px;
height: 200px;
```

### 合理的过渡时长
```css
/* ✅ 快速交互：0.2s - 0.3s */
.quick-transition {
    transition: all 0.2s;
}

/* ✅ 正常过渡：0.3s - 0.5s */
.normal-transition {
    transition: all 0.4s;
}

/* ❌ 过长：> 1s 用户等待 */
.slow-transition {
    transition: all 1.5s;  /* 太慢了 */
}
```
