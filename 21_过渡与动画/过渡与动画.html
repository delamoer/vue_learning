🎬 Vue 过渡与动画

让你的应用动起来 - Transition & Animation

1. 过渡系统概述

💡 什么是过渡？

Vue 提供了 <transition> 组件，用于在元素插入、更新或移除时添加过渡效果。

  • CSS 过渡：使用 transition 属性
  • CSS 动画：使用 @keyframes 和 animation
  • JavaScript 钩子：使用 JS 控制动画

2. 基础过渡效果

🎯 Demo 1：淡入淡出（Fade）
淡入淡出
<!-- HTML --> <transition name="fade"> <div v-if="show" class="box">淡入淡出</div> </transition> <!-- CSS --> .fade-enter-active, .fade-leave-active { transition: opacity 0.5s; } .fade-enter, .fade-leave-to { opacity: 0; }
🎯 Demo 2：滑动效果（Slide）
滑动效果
.slide-enter-active, .slide-leave-active { transition: all 0.5s; } .slide-enter { transform: translateX(-100px); opacity: 0; } .slide-leave-to { transform: translateX(100px); opacity: 0; }
🎯 Demo 3：缩放效果（Zoom）
缩放效果
.zoom-enter-active, .zoom-leave-active { transition: all 0.3s; } .zoom-enter, .zoom-leave-to { transform: scale(0); opacity: 0; }

3. 过渡的类名机制

📚 6 个过渡类名

Vue 在进入/离开过渡中，会自动添加以下类名（假设 name="fade"）：

类名 时机 说明
fade-enter 进入前 定义进入的开始状态
fade-enter-active 进入中 定义过渡过程（transition/animation）
fade-enter-to 进入后 定义进入的结束状态
fade-leave 离开前 定义离开的开始状态
fade-leave-active 离开中 定义过渡过程
fade-leave-to 离开后 定义离开的结束状态
// 过渡执行流程（进入）： 1. 元素插入前，添加 fade-enter 和 fade-enter-active 2. 一帧后，移除 fade-enter，添加 fade-enter-to 3. 过渡完成，移除 fade-enter-active 和 fade-enter-to // 过渡执行流程（离开）： 1. 触发离开前，添加 fade-leave 和 fade-leave-active 2. 一帧后，移除 fade-leave，添加 fade-leave-to 3. 过渡完成，移除元素和所有类名

4. CSS 动画（Animation）

🎯 Demo 4：弹跳效果（Bounce）
弹跳效果
.bounce-enter-active { animation: bounce-in 0.5s; } .bounce-leave-active { animation: bounce-out 0.5s; } @keyframes bounce-in { 0% { transform: scale(0); } 50% { transform: scale(1.2); } 100% { transform: scale(1); } } @keyframes bounce-out { 0% { transform: scale(1); } 50% { transform: scale(1.2); } 100% { transform: scale(0); } }
🎯 Demo 5：旋转淡入（Rotate）
旋转
.rotate-enter-active, .rotate-leave-active { transition: all 0.5s; } .rotate-enter, .rotate-leave-to { transform: rotate(180deg) scale(0); opacity: 0; }
🎯 Demo 6：翻转效果（Flip）
翻转
.flip-enter-active, .flip-leave-active { transition: all 0.5s; } .flip-enter, .flip-leave-to { transform: rotateY(180deg); opacity: 0; }

5. 初始渲染过渡

⚠️ 注意事项
  • 必须设置 key：多个元素切换时需要不同的 key
  • mode 属性：
    • in-out：新元素先进入，旧元素后离开
    • out-in：旧元素先离开，新元素后进入（常用）
<transition name="fade" mode="out-in"> <div v-if="view === 'A'" key="a">视图 A</div> <div v-else key="b">视图 B</div> </transition>

7. 列表过渡（transition-group）

🎯 Demo 9：列表动画 - 添加、删除、移动

<transition-group> 用于为列表中的每个元素添加过渡效果。

{{ item.title }}
{{ item.content }}
<!-- HTML --> <transition-group name="list" tag="div"> <div v-for="item in items" :key="item.id"> {{ item.title }} <button @click="remove(item.id)">删除</button> </div> </transition-group> <!-- CSS --> .list-enter-active, .list-leave-active { transition: all 0.5s; } .list-enter, .list-leave-to { opacity: 0; transform: translateY(30px); } .list-move { /* 其他元素移动时的过渡 */ transition: transform 0.5s; }
💡 关键点
  • tag 属性指定渲染的容器标签（默认 span）
  • 必须为每个子元素提供唯一的 key
  • .list-move 类名控制其他元素移动时的过渡

8. JavaScript 钩子

🎯 Demo 10：使用 JS 控制动画

可以在过渡的各个阶段触发 JavaScript 钩子函数。

JS 动画
<transition @before-enter="beforeEnter" @enter="enter" @after-enter="afterEnter" @before-leave="beforeLeave" @leave="leave" @after-leave="afterLeave" :css="false" <!-- 跳过 CSS 检测 --> > <div v-if="show">内容</div> </transition> methods: { beforeEnter(el) { el.style.opacity = '0'; el.style.transform = 'scale(0)'; }, enter(el, done) { // 强制重绘 el.offsetWidth; el.style.transition = 'all 0.5s'; el.style.opacity = '1'; el.style.transform = 'scale(1)'; // 动画完成后调用 done setTimeout(done, 500); }, afterEnter(el) { console.log('进入完成'); } }

10. 性能优化建议

✅ 最佳实践
  • 优先使用 CSS 过渡：性能更好，浏览器优化
  • 避免同时改变多个属性：影响性能
  • 使用 transform 代替 left/top：GPU 加速
  • 合理设置过渡时长：不要太长（用户等待）
  • 列表过渡添加 key：必须且唯一
  • CSS :css="false"：纯 JS 动画时禁用 CSS 检测
⚠️ 常见陷阱
  • ❌ 多元素过渡忘记设置 key → 过渡失效
  • ❌ transition-group 的子元素没有 key → 报错
  • ❌ 同时使用 v-if 和 v-show → v-show 无过渡效果
  • ❌ 在列表过渡中使用 display: inline → 移动过渡失效
  • ❌ JS 钩子的 enter/leave 忘记调用 done → 过渡卡住

11. 知识点总结

📚 核心要点
特性 用途 关键点
<transition> 单元素/组件过渡 v-if/v-show 触发
<transition-group> 列表过渡 必须有 key
CSS 过渡类名 定义过渡效果 6 个类名
JavaScript 钩子 JS 控制动画 记得调用 done()
mode 属性 控制过渡顺序 out-in 常用
appear 初始渲染过渡 首次也有动画
🎯 使用场景
✨ 适合使用过渡的场景：
  • 模态框/对话框显示隐藏
  • 提示消息/通知
  • 下拉菜单
  • Tab 切换
  • 路由切换
  • 列表项增删
🚀 性能优先属性：
  • opacity - 透明度
  • transform - 变换
  • scale - 缩放
  • rotate - 旋转
  • translate - 位移
