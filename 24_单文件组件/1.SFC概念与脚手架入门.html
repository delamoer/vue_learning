Demo 1

为什么需要单文件组件？

CDN 写法的局限性

❌ 样式污染

所有组件共享全局 CSS，大项目极易产生样式冲突，只能靠命名约定规避。

❌ 模板字符串难维护

template 写在 JS 字符串里，没有高亮、没有自动补全，嵌套结构一眼看不清。

❌ 没有模块系统

无法 import/export，组件只能挂全局变量，大项目命名冲突难以追踪。

❌ 无法使用预处理器

SCSS / TypeScript / JSX 统统无法直接使用，工程能力受限。

SFC 解决了什么

✅ scoped CSS

每个 <style scoped> 只作用于当前组件，彻底解决样式污染。

✅ 模板有编辑器支持

Volar / Vetur 插件提供语法高亮、Emmet、类型提示，开发体验飞跃。

✅ 真正的模块化

每个 .vue 是独立模块，import 按需引用，Tree-Shaking 自动生效。

✅ 预处理器随意用

一个属性切换：<script setup lang="ts"> 或 <style lang="scss">。

💡 SFC 本质上是一种约定：把一个组件的 模板、逻辑、样式 写在同一个 .vue 文件里，由构建工具（Vite/Webpack）在编译时拆分处理。
Demo 2

.vue 文件的三个核心块

▶ <template> 模板块
<template> <!-- 有且只有一个根元素（Vue 2 要求；Vue 3 已取消限制）--> <div class="user-card"> <h2>{{ user.name }}</h2> <p>年龄：{{ user.age }}</p> <button @click="handleClick">点我</button> </div> </template>
▶ <script> 逻辑块
<script> export default { name: 'UserCard', // 组件名 props: { userId: Number // 外部传入的 prop }, data() { return { user: { name: 'Alice', age: 25 } } }, methods: { handleClick() { this.$emit('select', this.user) } } } </script>
▶ <style scoped> 样式块
<style scoped> /* scoped：编译后自动加属性选择器，样式只作用于本组件 */ .user-card { background: #fff; border-radius: 8px; padding: 16px; } h2 { color: #333; } /* 仅限本组件内的 h2 */ </style>
⚠️ Vue 2 的 <template> 里必须有且只有一个根元素；Vue 3 支持多根节点（Fragment）。
💎 scoped 原理：编译后给元素加唯一属性如 data-v-7ba5bd90，CSS 选择器自动变为 .user-card[data-v-7ba5bd90]，从根上隔离样式。

动手创建第一个 Vite + Vue 2 项目

前置检查
$ node -v
v18.x.x   # 需要 Node.js 16+
$ npm -v
9.x.x
方案 A：Vite 官方模板（Vue 3，推荐新项目）
$ npm create vite@latest my-vue-app -- --template vue
$ cd my-vue-app
$ npm install
$ npm run dev
 
VITE v5.x.x ready in 300 ms
➜ Local: http://localhost:5173/
方案 B：配合本课程（Vite + Vue 2）
$ npm create vite@latest vue2-sfc-demo -- --template vanilla
$ cd vue2-sfc-demo
$ npm install vue@2 @vitejs/plugin-vue2

然后修改 vite.config.js：

import { defineConfig } from 'vite' import vue2 from '@vitejs/plugin-vue2' export default defineConfig({ plugins: [vue2()] })

将 main.js 改为：

import Vue from 'vue' import App from './App.vue' new Vue({ render: h => h(App) }).$mount('#app')
💡 Vue CLI 方式（了解）：npm install -g @vue/cli → vue create my-app → 选 Vue 2 预设。步骤更多但配套 GUI 工具（vue ui）更直观。

Vite + Vue 2 项目目录结构解析

初始化后的目录结构
vue2-sfc-demo/
 ├── vite.config.js     # Vite 配置，注册 vue2 插件
 ├── package.json      # 依赖声明，scripts 入口
 ├── index.html        # 应用入口 HTML（只有一个）
 ├── public/           # 静态资源，原样复制到 dist
 └── src/
     ├── main.js        # JS 入口，创建 Vue 实例
     ├── App.vue        # 根组件
     ├── components/    # 通用子组件
     │   ├── Header.vue
     │   └── UserCard.vue
     ├── views/         # 页面级组件（接 Router 用）
     │   ├── Home.vue
     │   └── About.vue
     └── assets/        # 图片、字体等资源
关键文件说明
  • 1

    index.html — 单页应用的唯一 HTML

    只有一个 <div id="app">，Vue 接管整个页面渲染，路由切换不刷新页面。

  • 2

    main.js — Vue 实例挂载点

    new Vue({ render: h => h(App) }).$mount('#app') 把根组件渲染进页面。

  • 3

    App.vue — 组件树的根

    所有页面组件都是 App 的子孙，Router 的 <router-view> 也放在这里。

  • 4

    components/ vs views/

    components/ 放可复用组件（按钮、卡片等）；views/ 放页面组件（与路由一一对应）。这是通行约定，并非强制。

组件引用方式（SFC 中）
<script> import UserCard from './components/UserCard.vue' export default { components: { UserCard } // 局部注册，只在本组件可用 } </script>

面试速答 + 练习任务

高频面试题
  • Q：什么是单文件组件（SFC）？
    一个以 .vue 为扩展名的文件，包含三个块：<template>（模板）、<script>（逻辑）、<style>（样式）。由 vue-loader / @vitejs/plugin-vue 在构建时解析，浏览器本身不能直接运行 .vue 文件。
  • Q：scoped CSS 的实现原理是什么？
    编译时给组件内所有 DOM 元素加一个唯一 hash 属性（如 data-v-abc123），同时把 <style scoped> 中的选择器自动追加属性选择器（如 .title[data-v-abc123]），从而将样式作用域锁定到当前组件。
  • Q：Vue CLI 与 Vite 的核心区别？
    Vue CLI 基于 Webpack，开发服务器需打包全部模块后启动，冷启动慢；Vite 利用浏览器原生 ES Module，按需编译，冷启动极快。生产构建 Vite 使用 Rollup，体积更小。
  • Q：为什么 Vue 2 的模板只能有一个根元素？
    Vue 2 的 render 函数只能返回单个 VNode 根节点，多个根节点无法表示。Vue 3 通过引入 Fragment（虚拟根节点）解决了这个限制。
  • Q：components/ 和 views/ 的区别？
    views/ 对应路由页面，每个视图通常是一个路由的展示入口；components/ 存放跨页面复用的通用 UI 组件。这是社区约定，框架本身不做区分。
  • Q：<script setup> 是什么？
    Vue 3.2 引入的语法糖，写在 <script setup> 内的代码等价于 Composition API 的 setup() 函数，省去 export default，变量和函数自动暴露给模板，更简洁。（Vue 2 不支持，但要了解趋势。）

🎯 本节完成后请动手：

  1. 环境搭建：按 Demo 4 的步骤创建 vue2-sfc-demo 项目，成功跑起 npm run dev
