scoped 的编译原理

加了 scoped 的样式，Vue CLI / Vite 编译时会做两件事：

第一步：给 DOM 打唯一 hash 属性
Card.vue（源码）
<template> <div class="card"> <h2 class="title">标题</h2> <p>内容</p> </div> </template> <style scoped> .card { border: 1px solid #ccc; } .title { color: red; } </style>
⟹ 编译后
浏览器中实际渲染
<!-- 每个元素加 hash 属性 --> <div class="card" data-v-7ba5bd90> <h2 class="title" data-v-7ba5bd90>标题</h2> <p data-v-7ba5bd90>内容</p> </div> /* CSS 选择器自动追加属性选择器 */ .card[data-v-7ba5bd90] { border: 1px solid #ccc; } .title[data-v-7ba5bd90] { color: red; }
💡 hash 值（如 data-v-7ba5bd90）由文件路径 + 内容生成，同一个文件每次构建结果一致，不同组件的 hash 必然不同——这就是样式隔离的根本。
子组件根元素的特殊行为

父组件的 scoped 样式能作用到子组件的根元素，但不能影响子组件内部：

/* 父组件 Parent.vue scoped 样式 */ .wrapper { padding: 20px; } /* ✅ 只影响父自身的 .wrapper */ /* 子组件 <MyCard /> 的根元素会同时带父、子两个 hash */ /* 所以父的根元素选择器 .my-card[data-v-父hash] 能命中子的根元素 */ .my-card { margin: 10px; } /* ✅ 能影响子组件根元素的外边距 */ .my-card .inner { } /* ❌ 无法影响子组件内部的 .inner */

深度选择器：穿透 scoped 影响子组件

使用第三方 UI 组件库（如 Element UI）时，需要覆盖库内部的样式，必须用深度选择器穿透 scoped。

三种写法对比
/* ❌ 普通 scoped 写法，无法穿透 */ <style scoped> .el-input__inner { border-radius: 0; } /* 编译为 .el-input__inner[data-v-xxx]，但库的 DOM 没有这个 hash，不生效 */ </style>
写法一：::v-deep（Vue CLI / Webpack，推荐）
<style scoped> /* 编译为：.wrapper[data-v-xxx] .el-input__inner */ /* hash 只加在左侧祖先，右侧不加 → 可以穿透子组件 */ .wrapper ::v-deep .el-input__inner { border-radius: 0; border-color: #6366f1; } </style>
写法二：/deep/（旧版语法，兼容 Vue CLI 2）
<style scoped> .wrapper /deep/ .el-input__inner { border-radius: 0; } </style>
写法三：>>>（纯 CSS，不支持预处理器）
<style scoped> .wrapper >>> .el-input__inner { border-radius: 0; } /* 使用 scss/less 时不支持 >>>，必须用 ::v-deep 或 /deep/ */ </style>
⚠️ 作用域最小化原则：深度选择器尽量加祖先限定（如 .wrapper ::v-deep .el-input），避免写成全局 ::v-deep .el-input，否则会无意中影响页面中所有同名元素。
实际场景：覆盖 Element UI 输入框样式
<template> <div class="search-box"> <el-input v-model="keyword" placeholder="搜索" /> </div> </template> <style scoped> /* 只影响当前组件内的 el-input，不污染其他页面的 el-input */ .search-box ::v-deep .el-input__inner { height: 48px; border-radius: 24px; padding-left: 20px; } </style>

全局样式 vs scoped：正确的组织方式

在同一个 .vue 文件里混用全局 + scoped
/* ✅ 一个组件可以有两个 style 块 */ /* Block 1：全局样式（没有 scoped）*/ <style> /* 影响全局，适合重置样式或定义全局 CSS 变量 */ :root { --primary: #6366f1; --radius: 8px; } </style> /* Block 2：局部 scoped 样式 */ <style scoped> .card { border-radius: var(--radius); /* 使用全局变量 */ border: 1px solid var(--primary); } </style>
推荐的全局样式组织结构
/* src/assets/styles/ 目录下 */ /* reset.css — 浏览器默认样式重置 */ *, *::before, *::after { box-sizing: border-box; margin: 0; } /* variables.css — CSS 自定义属性 */ :root { --primary: #6366f1; --text: #1e293b; } /* main.js 中统一引入 */ import './assets/styles/reset.css' import './assets/styles/variables.css'
使用 SCSS 变量（需安装 sass）
# 安装 sass（一次性） npm install -D sass /* 然后在 .vue 文件中直接用 */ <style lang="scss" scoped> // SCSS 变量和嵌套，开箱即用 $primary: #6366f1; .card { border: 1px solid $primary; &:hover { // SCSS 嵌套 & 伪类 box-shadow: 0 4px 12px rgba(99,102,241,0.2); } .title { // 嵌套子选择器 color: $primary; } } </style>
💡 scoped 和 lang="scss" 可以同时使用：<style lang="scss" scoped>，两者互不干扰——SCSS 先编译为 CSS，再由 Vue 加 scoped hash。
四种使用场景选择

✅ 用 scoped

大多数组件的私有样式，防止污染全局

🔧 用 ::v-deep

需要覆盖第三方组件库（Element UI 等）的内部样式

⚠️ 不加 scoped

全局 CSS 变量、字体、reset 样式；放在 App.vue 或独立 CSS 文件

🎯 用 CSS Modules

需要在 JS 中动态引用 class 名，或彻底避免命名冲突

CSS Modules：用 JS 引用 class 名

CSS Modules 是另一种样式隔离方案：class 名编译成唯一 hash 字符串，通过 $style.xxx 在模板/JS 中引用。

基本用法：<style module>
<template> <!-- 用 :class="$style.xxx" 引用（注意是动态绑定）--> <div :class="$style.card"> <h2 :class="$style.title">标题</h2> <!-- 多个 class --> <p :class="[$style.text, isActive && $style.active]"> 内容 </p> </div> </template> <style module> /* 类名会被编译为唯一 hash，如 _card_abc12_1 */ .card { border-radius: 8px; padding: 16px; } .title { color: #6366f1; } .text { color: #64748b; } .active { color: #10b981; font-weight: bold; } </style>
在 JS 中使用 class 名
export default { methods: { getCardClass() { // $style 对象包含所有 class 名的映射 console.log(this.$style) // { card: '_card_abc12_1', title: '_title_abc12_2', ... } return this.$style.card } } }
scoped vs CSS Modules 对比
scoped
// 模板中直接写 class 名 <div class="card"> // 编译后 DOM： <div class="card" data-v-7ba5bd>
CSS Modules
// 模板中动态绑定 <div :class="$style.card"> // 编译后 DOM： <div class="_card_abc12_1">
💎 实际项目 90% 用 scoped 就足够了。CSS Modules 的主要优势是可以在 JS 中编程式操作 class 引用，适合组件库开发或需要极致隔离的场景。

动态 class / style 绑定实战

:class 的四种写法（配合 scoped 使用）
<template> <!-- 写法一：三元表达式 --> <div :class="isActive ? 'active' : 'inactive'"> <!-- 写法二：对象语法（最常用）--> <div :class="{ active: isActive, disabled: isDisabled }"> <!-- 写法三：数组语法 --> <div :class="[baseClass, isActive && 'active']"> <!-- 写法四：静态 class + 动态 :class 共存 --> <div class="card" :class="{ 'card--active': isActive }"> <!-- 最终 class="card card--active" --> </template>
:style 动态内联样式
<template> <!-- 对象语法（camelCase）--> <div :style="{ backgroundColor: bgColor, fontSize: size + 'px' }"> <!-- 数组合并多个样式对象 --> <div :style="[baseStyles, themeStyles]"> </template> <script> export default { data() { return { bgColor: '#6366f1', size: 16, baseStyles: { padding: '16px', borderRadius: '8px' }, themeStyles: { background: '#f8fafc', color: '#1e293b' } } } } </script>
实战：状态驱动的按钮组件
<template> <button :class="[ 'btn', `btn--${type}`, { 'btn--loading': loading, 'btn--disabled': disabled } ]" :disabled="loading || disabled" @click="handleClick" > <span v-if="loading">⏳</span> <slot /> </button> </template> <style scoped> .btn { padding: 8px 16px; border-radius: 6px; cursor: pointer; } .btn--primary { background: #6366f1; color: white; } .btn--danger { background: #ef4444; color: white; } .btn--loading { opacity: 0.7; cursor: not-allowed; } .btn--disabled { opacity: 0.4; cursor: not-allowed; } </style>

常见坑 + 面试速答 + 练习

常见坑（面试也会考）
⚠️ 坑 1：v-html 动态插入的内容不会被 scoped CSS 影响，因为 Vue 不会给动态 HTML 加 hash 属性。需要用 ::v-deep 或移到全局样式里。
⚠️ 坑 2：<transition> 的过渡 class（如 .fade-enter-active）是 Vue 运行时动态添加的，不带 hash，在 scoped 样式里写不生效，必须放在全局或用 ::v-deep。
⚠️ 坑 3：多个同名组件在同一页面中，scoped 的 hash 是按文件路径生成的，路径相同的文件 hash 相同。不要把两个不同组件放在同一路径下命名相同。
⚠️ 坑 4：::v-deep 是 Vue 2 的写法；Vue 3 改为 :deep(.selector)。迁移时注意替换。
面试速答
  • Q：scoped CSS 的实现原理？
    编译时给组件内所有 DOM 元素加唯一 hash 属性（如 data-v-xxx），同时把 <style scoped> 中的选择器自动添加属性选择器后缀（如 .title[data-v-xxx]），从根本上将样式作用域锁定在当前组件。
  • Q：如何在 scoped 组件里覆盖第三方库的样式？
    使用深度选择器 ::v-deep（Vue CLI）或 :deep()（Vue 3 / Vite）。编译后 hash 只加在左侧祖先选择器，右侧选择器不加 hash，从而能命中子组件或第三方库内部的 DOM 元素。
  • Q：scoped 和 CSS Modules 的区别？
    scoped：给 DOM 加属性，选择器加属性过滤，class 名本身不变，模板写法不变；CSS Modules：class 名本身编译成唯一 hash 字符串，模板需用 :class="$style.xxx" 动态绑定，可在 JS 中直接引用 class 名。日常项目 scoped 足够，组件库开发更多用 CSS Modules。
  • Q：为什么 v-html 的内容 scoped 样式不生效？
    v-html 直接把字符串作为 innerHTML 插入，Vue 的编译器无法给这些动态 HTML 元素打 hash 属性，所以 scoped 样式的属性选择器无法命中。解决方法：用 ::v-deep 或将相关样式放在无 scoped 的全局样式块里。
