项目设计：组件拆分与数据架构

一个 TodoList 包含：添加输入框、任务列表、每条任务、底部统计栏。按照单一职责原则拆为 4 个组件：

组件树结构
App.vue数据中枢 · 状态持久化
├─TodoHeader.vueaddTodo@add
├─TodoList.vue:todos
│ └─TodoItem.vue:todo@toggle @delete
└─TodoFooter.vue:total :doneCount@clear-done
核心数据结构（App.vue 中）
// todos 数组存在 App.vue 的 data 中（提升到公共祖先） todos: [ { id: 1, title: '学习 Vue SFC', done: true }, { id: 2, title: '完成综合实践', done: false }, { id: 3, title: '刷面试题', done: false } ]
数据流
1
TodoHeader 用户输入 → emit add({id, title, done:false}) → App 把新 todo push 进 todos
2
App 通过 :todos prop 传给 TodoList，TodoList 再 v-for 传给每个 TodoItem
3
TodoItem 勾选 → emit toggle(id)；删除 → emit delete(id)；逐层往上冒泡到 App 处理
4
TodoFooter 读取 total/doneCount 展示，emit clear-done 清除已完成
💡 状态提升原则：把数据放在需要它的组件们的最近公共祖先。这里 4 个组件都要访问 todos，所以放在 App.vue。
Demo 2

App.vue：数据中枢 + localStorage 持久化

App.vue
<template> <div class="app"> <h1 class="app-title">✅ My Todos</h1> <TodoHeader @add="addTodo" /> <TodoList :todos="todos" @toggle="toggleTodo" @delete="deleteTodo" /> <TodoFooter :total="todos.length" :done-count="doneCount" @clear-done="clearDone" /> </div> </template> <script> import TodoHeader from './components/TodoHeader.vue' import TodoList from './components/TodoList.vue' import TodoFooter from './components/TodoFooter.vue' export default { name: 'App', components: { TodoHeader, TodoList, TodoFooter }, data() { // 首次加载从 localStorage 读取，没有则用默认值 const saved = localStorage.getItem('vue-todos') return { todos: saved ? JSON.parse(saved) : [ { id: 1, title: '学习 Vue SFC', done: true }, { id: 2, title: '完成综合实践', done: false }, ] } }, computed: { doneCount() { return this.todos.filter(t => t.done).length } }, watch: { // 深度监视 todos，每次变化自动持久化 todos: { handler(val) { localStorage.setItem('vue-todos', JSON.stringify(val)) }, deep: true } }, methods: { addTodo(todo) { this.todos.unshift(todo) }, toggleTodo(id) { const t = this.todos.find(t => t.id === id); if(t) t.done = !t.done }, deleteTodo(id) { this.todos = this.todos.filter(t => t.id !== id) }, clearDone() { this.todos = this.todos.filter(t => !t.done) } } } </script> <style scoped> .app { max-width: 520px; margin: 40px auto; padding: 0 16px; } .app-title { text-align: center; color: #6366f1; font-size: 1.8rem; margin-bottom: 24px; } </style>
⚠️ 注意 watch todos deep:true 时，修改 todo.done 这类嵌套属性也能触发。但如果用 this.todos[0].done = true 直接下标赋值，Vue 2 检测不到——必须通过 find 拿到引用后修改，或用 Vue.set。

TodoHeader.vue + TodoFooter.vue

TodoHeader.vue
<template> <div class="header"> <input v-model.trim="inputVal" placeholder="添加新任务..." @keyup.enter="submit" /> <button @click="submit">添加</button> </div> </template> <script> export default { name: 'TodoHeader', data() { return { inputVal: '' } }, methods: { submit() { if (!this.inputVal) return this.$emit('add', { id: Date.now(), title: this.inputVal, done: false }) this.inputVal = '' } } } </script> <style scoped> .header { display: flex; gap: 8px; margin-bottom: 16px; } .header input { flex: 1; padding: 10px 14px; border: 2px solid #e2e8f0; border-radius: 8px; font-size: 1rem; } .header input:focus { outline: none; border-color: #6366f1; } .header button { padding: 10px 18px; background: #6366f1; color: white; border: none; border-radius: 8px; cursor: pointer; font-size: 1rem; } </style>
TodoFooter.vue
<template> <div class="footer"> <span> 已完成 <strong>{{ doneCount }}</strong> / {{ total }} </span> <button v-show="doneCount > 0" @click="$emit('clear-done')" >清除已完成</button> </div> </template> <script> export default { name: 'TodoFooter', props: { total: { type: Number, required: true }, doneCount: { type: Number, required: true } } } </script> <style scoped> .footer { display: flex; justify-content: space-between; align-items: center; padding: 12px 0; border-top: 1px solid #e2e8f0; color: #64748b; font-size: 0.9rem; } .footer strong { color: #6366f1; } .footer button { background: none; border: 1px solid #ef4444; color: #ef4444; border-radius: 6px; padding: 4px 12px; cursor: pointer; } </style>
Demo 4

TodoList.vue + TodoItem.vue（事件冒泡链）

TodoList.vue（透传事件）
<template> <ul class="list"> <!-- 没有任务时的空状态 --> <li v-if="todos.length === 0" class="empty"> 暂无任务，添加一个吧 🎉 </li> <!-- 升序渲染：未完成在前 --> <TodoItem v-for="todo in sortedTodos" :key="todo.id" :todo="todo" @toggle="$emit('toggle', $event)" @delete="$emit('delete', $event)" /> </ul> </template> <script> import TodoItem from './TodoItem.vue' export default { name: 'TodoList', components: { TodoItem }, props: { todos: Array }, computed: { sortedTodos() { // 未完成排前面，已完成排后面 return [...this.todos].sort((a,b) => a.done - b.done) } } } </script> <style scoped> .list { list-style: none; padding: 0; } .empty { text-align: center; color: #94a3b8; padding: 40px 0; } </style>
TodoItem.vue（叶子组件）
<template> <li :class="['item', { done: todo.done }]"> <input type="checkbox" :checked="todo.done" @change="$emit('toggle', todo.id)" /> <span class="title">{{ todo.title }}</span> <button class="del" @click="$emit('delete', todo.id)" >✕</button> </li> </template> <script> export default { name: 'TodoItem', props: { todo: { type: Object, required: true } } } </script> <style scoped> .item { display: flex; align-items: center; gap: 12px; padding: 12px 0; border-bottom: 1px solid #f1f5f9; transition: opacity 0.2s; } .item.done { opacity: 0.5; } .item.done .title { text-decoration: line-through; } .title { flex: 1; color: #374151; } .del { background: none; border: none; color: #ef4444; cursor: pointer; font-size: 1rem; opacity: 0; transition: opacity 0.15s; } .item:hover .del { opacity: 1; } </style>
💡 TodoList 只是事件的"中转站"，用 @toggle="$emit('toggle', $event)" 把事件往上传。这是多层组件中 emit 链路 的标准写法，也是引出 EventBus / Vuex 必要性的经典场景。

知识汇总 + 扩展练习 + 下一阶段预告

本项目用到的核心知识点
📦

SFC 组件结构

template / script / style 三段式，每个文件独立一个组件职责

📡

props 向下

App → TodoList → TodoItem 逐层传 todo 数据，类型约束 required

📣

emit 向上

TodoItem → TodoList → App 事件冒泡，$emit 链路最佳实践

🎨

scoped CSS

每个组件独立的样式作用域，.done、.item:hover 等不相互污染

👁️

watch deep + localStorage

深度监视 todos 数组，变化时自动序列化持久化到 localStorage

🔢

computed + 状态派生

doneCount 从 todos 派生，sortedTodos 按 done 字段排序

扩展练习（进阶方向）

⭐ 初级扩展

  1. 双击编辑：给 TodoItem 加 @dblclick，双击变成输入框，回车保存
  2. 过滤标签：在 TodoFooter 加「全部 / 未完成 / 已完成」三个过滤按钮，通过 emit 传给 App 过滤显示
  3. 拖拽排序：用 HTML5 draggable 实现任务上下拖动顺序调整

⭐⭐ 进阶扩展

  1. 优先级：todo 对象加 priority 字段（1-3），用 scoped 样式给不同优先级加颜色标签
  2. 截止日期：加 deadline 字段，超期用红色 ::v-deep 高亮，watch 判断今日到期的任务推送提示
  3. Vuex 重构：把 App.vue 中的 todos 状态迁移到 Vuex store，体验状态管理的优势
