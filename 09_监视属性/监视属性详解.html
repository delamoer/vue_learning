Demo 1: 什么是监视属性（watch）？
定义：监视属性用于观察和响应数据的变化
特点：
  • 数据变化时自动执行回调函数
  • 可以执行异步操作（computed不可以）
  • 可以访问旧值和新值
  • 适合在数据变化时执行副作用操作（API调用、localStorage等）

Demo 3: 深度监视（deep: true）⭐ 重要
问题：默认情况下，watch只监视对象的引用变化，不监视内部属性变化
解决：使用 deep: true 开启深度监视
应用：任务管理系统中的 localStorage持久化（最重要的应用场景）

// ❌ 错误示例：无法监视到对象内部变化 watch: { tasks(newValue) { // 只有tasks被重新赋值时才会触发 // 修改tasks[0].completed不会触发！ localStorage.setItem('tasks', JSON.stringify(newValue)); } } // ✅ 正确示例：使用deep深度监视 watch: { tasks: { // handler: 处理函数 handler(newValue) { console.log('任务数据变化，保存到localStorage'); localStorage.setItem('tasks', JSON.stringify(newValue)); }, // deep: 开启深度监视 deep: true } } // 📌 任务管理系统实际使用 watch: { tasks: { handler(newValue) { // 任何任务的增删改都会触发这里 // 实现自动保存到localStorage localStorage.setItem('vue_tasks', JSON.stringify(newValue)); }, deep: true } }
⚠️ 性能注意事项
deep: true会遍历对象的所有属性，数据量大时可能影响性能
解决方案：
1. 如果只需要监视某个属性，使用 'tasks[0].completed' 而不是整个对象
2. 合理使用防抖（debounce）减少不必要的保存
Demo 4: immediate 立即执行
问题：默认情况下，watch在数据首次加载时不会执行
解决：使用 immediate: true 让侦听器立即执行一次
应用：页面初始化时就需要根据数据执行操作

Demo 6: Watch vs Computed 对比 ⭐ 重要
核心区别：
- Computed：用于计算并返回一个新值（声明式）
- Watch：用于观察数据变化并执行操作（命令式）

对比表格

特性 Computed 计算属性 Watch 监视属性
主要用途 计算派生数据 执行副作用操作
返回值 必须返回值 无返回值
缓存 ✅ 有缓存 ❌ 无缓存
异步操作 ❌ 不支持 ✅ 支持
访问旧值 ❌ 不支持 ✅ 支持（oldValue）
典型场景 过滤列表、统计数据、格式化 API调用、localStorage、日志记录

使用选择

✅ 使用 Computed 的场景：
1. 需要根据已有数据计算新数据（如：总价、过滤列表）
2. 需要在模板中显示计算结果
3. 需要缓存机制提高性能
4. 逻辑是同步的
✅ 使用 Watch 的场景：
1. 数据变化时需要执行异步操作（API调用、定时器）
2. 需要执行副作用操作（localStorage、日志）
3. 需要访问变化前的值（oldValue）
4. 监视深层对象变化（deep: true）
// ✅ 使用Computed：计算派生数据 computed: { fullName() { return this.firstName + ' ' + this.lastName; }, filteredTasks() { return this.tasks.filter(t => t.completed); } } // ✅ 使用Watch：执行副作用 watch: { // 数据变化时保存到localStorage tasks: { handler(newValue) { localStorage.setItem('tasks', JSON.stringify(newValue)); }, deep: true }, // 搜索词变化时发送API请求 searchKeyword(newValue) { this.fetchSearchResults(newValue); } } // ❌ 不要用Watch做计算（应该用Computed） watch: { firstName() { this.fullName = this.firstName + ' ' + this.lastName; // ❌ 错误 } }
📚 知识点总结

Watch 完整配置选项

watch: { // 方式1：简写（只有handler） message(newValue, oldValue) { console.log(newValue, oldValue); }, // 方式2：完整写法 tasks: { // handler: 处理函数 handler(newValue, oldValue) { // 数据变化时的处理逻辑 }, // deep: 深度监视（监视对象内部变化） deep: true, // immediate: 立即执行（页面加载时就执行一次） immediate: true }, // 方式3：监视对象的属性 'user.name'(newValue, oldValue) { console.log('用户名改变'); } } // 方式4：使用$watch动态添加监视 this.$watch('message', function(newValue, oldValue) { console.log(newValue); }, { deep: true, immediate: true });

🎯 任务管理系统中的实际应用

// 任务管理系统中最重要的watch应用 watch: { // 监视tasks数组的深度变化，自动保存到localStorage tasks: { handler(newValue) { // 任何任务的增删改都会触发这里 // 包括： // - 添加新任务 // - 删除任务 // - 修改任务标题 // - 切换完成状态 // - 修改优先级 // 保存到localStorage实现持久化 localStorage.setItem('vue_tasks', JSON.stringify(newValue)); console.log('任务数据已自动保存'); }, // deep: true 是关键！ // 没有deep，修改tasks[0].completed不会触发handler deep: true } }, // 在created中从localStorage恢复数据 created() { const savedTasks = localStorage.getItem('vue_tasks'); if (savedTasks) { this.tasks = JSON.parse(savedTasks); } }

⚠️ 常见错误

错误1：忘记使用deep监视对象
// ❌ 错误：无法监视到tasks[0].completed的变化 watch: { tasks(newValue) { localStorage.setItem('tasks', JSON.stringify(newValue)); } } // ✅ 正确：使用deep watch: { tasks: { handler(newValue) { localStorage.setItem('tasks', JSON.stringify(newValue)); }, deep: true // 必须加这个！ } }
错误2：在computed中使用watch的逻辑
// ❌ 错误：用watch计算fullName watch: { firstName() { this.fullName = this.firstName + this.lastName; }, lastName() { this.fullName = this.firstName + this.lastName; } } // ✅ 正确：使用computed computed: { fullName() { return this.firstName + this.lastName; } }
错误3：在handler中执行耗时操作不加防抖
// ❌ 错误：每次输入都发送请求 watch: { searchKeyword(newValue) { this.fetchResults(newValue); // 输入"hello"会发送5次请求！ } } // ✅ 正确：使用防抖 watch: { searchKeyword(newValue) { clearTimeout(this.timer); this.timer = setTimeout(() => { this.fetchResults(newValue); }, 300); // 300ms后才发送请求 } }
