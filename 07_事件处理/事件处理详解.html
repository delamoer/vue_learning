Demo 1: 事件绑定基础
语法：v-on:事件名="处理方法" 或 @事件名="处理方法"
常用事件：@click, @input, @change, @submit, @keyup等
传参方式：
  • 无参数：@click="handleClick"
  • 有参数：@click="handleClick(123)"
  • 获取事件对象：@click="handleClick($event)"

Demo 2: 事件修饰符 ⭐ 重要
作用：简化事件处理逻辑，避免在方法中写event.preventDefault()等代码
常用修饰符：
  • .stop - 阻止事件冒泡（相当于event.stopPropagation()）
  • .prevent - 阻止默认行为（相当于event.preventDefault()）
  • .capture - 使用事件捕获模式
  • .self - 只当事件在该元素本身触发时才触发回调
  • .once - 事件只触发一次

Demo 6: @mousedown.prevent 模式 ⭐ 任务管理系统应用
问题场景：编辑输入框时，点击保存/取消按钮会先触发input的@blur事件，导致逻辑冲突
解决方案：在按钮上使用 @mousedown.prevent 阻止blur事件触发
实际应用：任务管理系统的编辑功能（这是修复BUG时使用的技巧）

任务编辑示例（任务管理系统实际应用）

🔧 技术要点
问题：点击保存按钮时，input的@blur先触发，可能导致状态混乱
解决：使用@mousedown.prevent代替@click，阻止blur事件
原理：mousedown在blur之前触发，prevent阻止focus transfer
📋 编辑操作日志
{{ log.time }} {{ log.message }}
// ❌ 错误写法：使用@click会导致blur先触发 <input type="text" v-model="title" @blur="cancelEdit"> // 点击保存按钮时：blur先触发 → 退出编辑 → click晚触发 → 数据丢失 <button @click="saveEdit">保存</button> // ✅ 正确写法：使用@mousedown.prevent ⭐ 重要 <input type="text" v-model="title" @blur="cancelEdit"> // mousedown在blur之前触发，prevent阻止blur <button @mousedown.prevent="saveEdit">保存</button> <button @mousedown.prevent="cancelEdit">取消</button> // 📌 任务管理系统中的实际应用 // TodoItem组件中的编辑功能就使用了这个技巧 <template v-else> <input type="text" v-model="editingTitle" @blur="cancelEdit" ref="editInput"> <button @mousedown.prevent="saveEdit">保存</button> <button @mousedown.prevent="cancelEdit">取消</button> </template>
💡 事件触发顺序
使用@click时：
1. mousedown → 2. blur（输入框失焦）→ 3. click

使用@mousedown.prevent时：
1. mousedown（同时阻止后续focus变化）→ 2. 不触发blur → 3. 逻辑正确执行

事件修饰符速查表

修饰符 作用 等价代码 应用场景
.stop 阻止事件冒泡 event.stopPropagation() 嵌套元素点击
.prevent 阻止默认行为 event.preventDefault() 表单提交、链接跳转
.capture 捕获模式 addEventListener(事件, 函数, true) 特殊事件处理顺序
.self 只在自身触发 event.target === event.currentTarget 模态框遮罩层
.once 只触发一次 手动移除监听器 一次性操作
.passive 不阻止默认行为 addEventListener(事件, 函数, {passive: true}) 滚动性能优化

⚠️ 常见错误

错误1：修饰符顺序错误
// ❌ 错误：先prevent再stop <a @click.prevent.stop="handleClick"></a> // ✅ 正确：通常先stop再prevent <a @click.stop.prevent="handleClick"></a>
错误2：编辑模式使用@click而不是@mousedown.prevent
// ❌ 错误：blur会先触发，导致编辑状态丢失 <input @blur="cancel"> <button @click="save">保存</button> // ✅ 正确：使用mousedown.prevent <input @blur="cancel"> <button @mousedown.prevent="save">保存</button>
错误3：忘记在表单上使用 prevent
// ❌ 错误：表单提交会刷新页面 <form @submit="handleSubmit"></form> // ✅ 正确：阻止默认提交行为 <form @submit.prevent="handleSubmit"></form>
