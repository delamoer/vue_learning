🎨 Vue 2 过滤器完整学习案例

Filters - 文本格式化的便捷工具（Vue 3 已移除，推荐使用计算属性）

📅 1. 日期格式化过滤器

将时间戳转换为可读的日期格式
// 过滤器定义
                Vue.filter('formatDate', function(value, format = 'YYYY-MM-DD') {
                // ... 日期格式化逻辑
                })

                // 使用方式
                {{ timestamp | formatDate }}
                {{ timestamp | formatDate('YYYY-MM-DD HH:mm:ss') }}
原始时间戳：{{ timestamp }}
默认格式：{{ timestamp | formatDate }}
完整格式：{{ timestamp | formatDate('YYYY-MM-DD HH:mm:ss') }}
中文格式：{{ timestamp | formatDate('YYYY年MM月DD日 HH:mm') }}
仅时间：{{ timestamp | formatDate('HH:mm:ss') }}

💰 2. 货币格式化过滤器

将数字转换为货币格式（千分位 + 货币符号）
// 过滤器定义
                Vue.filter('currency', function(value, symbol = '¥', decimals = 2) {
                // ... 货币格式化逻辑
                })

                // 使用方式
                {{ price | currency }}
                {{ price | currency('$', 2) }}
原始金额：{{ price }}
人民币：{{ price | currency }}
美元：{{ price | currency('$', 2) }}
欧元：{{ price | currency('€', 2) }}
无小数：{{ price | currency('￥', 0) }}

📝 3. 文本转换过滤器

大小写转换、文本截取等
原始文本：{{ textInput }}
首字母大写：{{ textInput | capitalize }}
全部大写：{{ textInput | uppercase }}
全部小写：{{ textInput | lowercase }}
截取前10字符：{{ textInput | truncate(10) }}
带省略号截取：{{ textInput | truncate(15, '...') }}

🔢 4. 数字格式化过滤器

小数位、百分比、千分位等
原始数字：{{ numberInput }}
保留2位小数：{{ numberInput | toFixed(2) }}
百分比：{{ numberInput | percent }}
千分位：{{ numberInput | numberFormat }}
文件大小：{{ numberInput | fileSize }}

🔄 5. 状态转换过滤器

将数字或布尔值转换为可读文本
布尔值 true：{{ true | statusText }}
布尔值 false：{{ false | statusText }}
数字 1：{{ 1 | statusText }}
数字 0：{{ 0 | statusText }}
性别 1：{{ 1 | genderText }}
性别 0：{{ 0 | genderText }}

⛓️ 6. 过滤器串联使用

多个过滤器可以串联，从左到右依次执行
// 串联语法
                    {{ message | filter1 | filter2 | filter3 }}

                    // 执行顺序：message → filter1 → filter2 → filter3
原始文本：{{ longText }}
截取 + 大写：{{ longText | truncate(20) | uppercase }}
大写 + 截取：{{ longText | uppercase | truncate(20) }}

🎯 7. 局部过滤器 vs 全局过滤器

局部过滤器只在定义它的 Vue 实例中可用
// 全局过滤器定义（所有实例都可用）
                  Vue.filter('uppercase', function(value) {
                    return value.toString().toUpperCase();
                  });

                  // 局部过滤器定义（仅当前实例可用）
                  new Vue({
                    el: '#root',
                    filters: {
                      reverse(value) {
                        return value.toString().split('').reverse().join('');
                      },
                      repeat(value, times = 2) {
                        return value.toString().repeat(times);
                      }
                    }
                  });
原始文本：{{ localFilterTest }}
【全局】大写：{{ localFilterTest | uppercase }}
【局部】反转：{{ localFilterTest | reverse }}
【局部】重复2次：{{ localFilterTest | repeat(2) }}
【局部】重复3次：{{ localFilterTest | repeat(3) }}
【局部】占位符：{{ emptyValue | placeholder('暂无数据') }}

📌 全局过滤器 vs 局部过滤器的区别
  • 全局过滤器：使用 Vue.filter('name', fn) 定义，在所有 Vue 实例中都可以使用
  • 局部过滤器：在 Vue 实例的 filters 选项中定义，只能在当前实例中使用
  • 优先级：当全局过滤器和局部过滤器同名时，局部过滤器优先
  • 使用场景：通用的格式化用全局过滤器，特定组件的用局部过滤器
⚠️ Vue 3 重要变化

Vue 3 已经完全移除了过滤器功能，官方推荐使用以下替代方案：

  • 计算属性 - 用于需要缓存的复杂逻辑
  • 方法 - 用于简单的格式化逻辑
// Vue 3 替代方案示例
                computed: {
                formattedDate() {
                    return this.formatDate(this.timestamp);
                }
                }

                // 或者使用方法
                methods: {
                formatDate(value) {
                    return new Date(value).toLocaleDateString();
                }
                }

                // 模板中使用
                {{ formattedDate }}
                {{ formatDate(timestamp) }}
💡 学习建议
  • 如果是学习 Vue 2：了解过滤器的用法，快速过一遍即可
  • 如果准备用 Vue 3：重点学习计算属性和方法，过滤器了解概念即可
  • 维护老项目时需要了解过滤器，因为很多 Vue 2 项目在使用
  • 新项目建议直接用 Vue 3 的方式（计算属性/方法）
