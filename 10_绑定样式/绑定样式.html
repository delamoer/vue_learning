📚 Vue样式绑定完全指南

本教程详细讲解Vue中的样式绑定，包括class和style的各种用法及实战案例

Demo 1: Class 字符串写法
适用场景：样式类名不确定，需要动态切换整个类名
语法：:class="变量名"
特点：变量的值直接作为类名
当前心情：{{ moodText }} - 点击切换
// HTML <div class="basic" :class="mood">{{ moodText }}</div> // JavaScript data() { return { mood: 'normal' // 变量值直接作为类名 } }
Demo 2: Class 数组写法
适用场景：需要同时应用多个动态类名
语法：:class="[class1, class2, class3]"
特点：数组中可以包含字符串、变量、三元表达式、对象
// HTML - 数组中可以混合使用字符串、变量、三元表达式 <button :class="[btnType, btnSize, isDisabled ? 'btn-disabled' : '']"></button> // JavaScript data() { return { btnType: 'btn-primary', btnSize: '', isDisabled: false } }
Demo 3: Class 对象写法 ⭐ 最常用
适用场景：类名确定，但需要根据条件决定是否应用（最常用！）
语法：:class="{ className: 条件 }"
特点：条件为true时应用该类，false时不应用。这是任务管理系统中最常用的方式！

任务列表示例（类似任务管理系统）

{{ task.title }}
// HTML - 对象写法：key是类名，value是布尔值条件 <div :class="['task-item', { completed: task.completed, // task.completed为true时应用completed类 urgent: task.urgent, // task.urgent为true时应用urgent类 editing: task.editing // task.editing为true时应用editing类 }]"></div> // 可以简写为（如果只有动态类名）： <div :class="{ completed: task.completed, urgent: task.urgent }"></div> // JavaScript data() { return { tasks: [ { id: 1, title: '学习Vue', completed: false, urgent: true } ] } }
Demo 4: 标签切换（对象写法实战）
应用场景：筛选按钮、标签页切换等
核心技巧：{ active: currentTab === tab.value }
{{ tab.label }}
当前选中：{{ currentTabLabel }}
// HTML - 关键：currentTab === tab.value 判断是否为当前激活项 <span :class="['tag', { active: currentTab === tab.value, // 当前选中时应用active类 inactive: currentTab !== tab.value // 未选中时应用inactive类 }]"></span> // 这和任务管理系统中的筛选器是一样的原理： <button :class="['filter-btn', { active: currentFilter === 'all' }]">全部</button>
Demo 5: Style 对象写法
适用场景：样式值需要动态计算（如颜色、尺寸、位置等）
语法：:style="{ fontSize: size + 'px', color: color }"
注意：CSS属性名使用驼峰式（fontSize）或短横线（'font-size'）
动态样式文本
// HTML - style对象写法 <div :style="{ fontSize: fontSize + 'px', // 注意要加单位 color: textColor, // 颜色值 backgroundColor: bgColor // 驼峰式命名 }"></div> // 也可以写成： <div :style="styleObject"></div> data() { return { styleObject: { fontSize: '20px', color: 'red' } } }
Demo 6: 进度条实战（Style + Class 组合）
应用场景：进度条、加载状态等
技巧：style控制宽度，class控制颜色
{{ progress }}%
// HTML - 组合使用class和style <div :class="{ 'progress-low': progress < 30, // <30%显示红色 'progress-medium': progress >= 30 && progress < 70, // 30-70%橙色 'progress-high': progress >= 70 // >=70%绿色 }" :style="{ width: progress + '%' }"> // 动态宽度 </div>
Demo 7: 卡片选择（综合应用）
应用场景：商品选择、选项卡等
技巧：多种状态的组合判断

📖 知识点总结

Class 绑定三种方式对比

写法 语法 适用场景 使用频率
字符串 :class="className" 类名完全动态切换 ⭐⭐
数组 :class="[class1, class2]" 需要同时应用多个类 ⭐⭐⭐
对象 ⭐ :class="{ active: isActive }" 根据条件决定是否应用类 ⭐⭐⭐⭐⭐ 最常用！

Style 绑定

  • 对象写法：:style="{ fontSize: '20px', color: 'red' }"
  • 数组写法：:style="[styleObj1, styleObj2]"
  • 注意：CSS属性名用驼峰式（fontSize）或短横线加引号（'font-size'）

实战技巧

  • ✅ 最常用：对象写法，如 { completed: task.completed }
  • ✅ 组合使用：:class="['base', { active: isActive }]"
  • ✅ 复杂条件：可以使用计算属性返回class对象
  • ✅ Style + Class：style控制数值，class控制状态颜色
// 任务管理系统中的真实用法： // 1. 筛选按钮 <button :class="['filter-btn', { active: currentFilter === 'all' }]">全部</button> // 2. 任务项状态 <div :class="['todo-item', { completed: task.completed, editing: isEditing }]"></div> // 3. 优先级颜色 <div :class="'priority-' + task.priority"></div> // 'priority-high' // 4. 标签状态 <span :class="['priority-text', task.priority]"></span> // class="priority-text high"
