🕰️ 23.4 生命周期深入详解

掌握组件从创建到销毁的全流程，理解父子组件钩子执行顺序

🎯 本节目标

  • 准确说出每个生命周期钩子的职责与可做/不可做的事
  • 掌握父子组件挂载与更新阶段的钩子顺序
  • 能在项目里正确放置请求、DOM 操作、清理逻辑

🗺️ 生命周期主线

初始化阶段：beforeCreate → created
挂载阶段：beforeMount → mounted
更新阶段：beforeUpdate → updated
销毁阶段：beforeDestroy → destroyed
记忆口诀：创-挂-更-销（每段前后各一个钩子）。

📘 Demo 3：更新阶段做什么最合适

beforeUpdate
数据已变，DOM 还是旧的。适合：更新前状态记录。
updated
DOM 已更新。适合：依赖新 DOM 的轻量操作（必要时配合 $nextTick）。
避免在 updated 里再次无条件改数据，否则可能形成更新循环。

📘 Demo 5：常见面试题速答

  • Q1：created 和 mounted 区别？
    答：created 可拿到数据/方法但拿不到真实 DOM；mounted 可操作真实 DOM。
  • Q2：请求数据放哪？
    答：常见放 created/mounted；若不依赖 DOM，优先 created。
  • Q3：父子 mounted 谁先？
    答：子 mounted 先于父 mounted。
  • Q4：销毁前要做什么？
    答：清定时器、解绑事件、销毁第三方实例，防内存泄漏。
