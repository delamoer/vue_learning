📥 组件通信：$emit（子传父）

$emit - 子组件向父组件发送消息

💡 1. 什么是$emit？

$emit是子组件向父组件传递消息的通道
父组件
监听事件：@my-event
⬆️ 通过 $emit 触发事件
子组件
触发事件：this.$emit('my-event', data) 
// 子组件：触发自定义事件
const ChildComponent = {
  methods: {
    notifyParent() {
      this.$emit('my-event', '来自子组件的消息');  // 触发事件，传递数据
    }
  },
  template: `
    <button @click="notifyParent">通知父组件</button>
  `
}

// 父组件：监听自定义事件
<child-component @my-event="handleEvent"></child-component>

methods: {
  handleEvent(message) {
    console.log(message);  // '来自子组件的消息'
  }
}

演示效果：

✅ 核心理解
  • 子→父：子组件通过$emit触发事件通知父组件
  • 类比：就像回调函数，子组件"调用"父组件的方法
  • 传递数据：可以把数据作为参数传给父组件
  • 配合props：props下发数据，$emit返回结果

🎯 1.1 简单理解：$emit就是"回调函数"

⭐ 最简单粗暴的理解方式
💡 一句话理解$emit

如果props是函数参数，那么$emit就是回调函数！子组件执行回调，父组件处理结果。

对比：回调函数 vs $emit

// 📌 JavaScript回调函数
function fetchData(callback) {        // 接收回调函数
  const data = '获取的数据';
  callback(data);                     // 执行回调，传递数据
}

fetchData((result) => {               // 传入回调函数
  console.log(result);                // 处理数据
});


// 📌 Vue组件的$emit（原理相同）
// 子组件：触发事件（相当于执行回调）
const Child = {
  methods: {
    sendData() {
      const data = '获取的数据';
      this.$emit('data-ready', data); // 触发事件，传递数据
    }
  }
}

// 父组件：监听事件（相当于传入回调）
<child @data-ready="handleData"></child>
methods: {
  handleData(result) {
    console.log(result);              // 处理数据
  }
}

更详细的对比：

JavaScript回调 Vue $emit 说明
function(callback) @event-name="handler" 定义回调/监听事件
callback(data) $emit('event-name', data) 执行回调/触发事件
调用方传入回调函数 父组件传入事件处理器 谁来处理
被调用方执行回调 子组件触发事件 谁来触发
通过参数传递数据 通过$emit参数传递数据 数据传递
✅ 这个类比帮助理解：
  • $emit就是"调用回调"：子组件触发事件就像执行回调函数
  • @监听就是"传入回调"：父组件监听事件就像传入回调函数
  • 数据向上传递：通过$emit的参数把数据传给父组件
  • 父子配合：props传数据下去，$emit把结果传回来

📝 2. $emit基本用法

如何触发和监听自定义事件

第一步：子组件触发事件

const ChildComponent = {
  methods: {
    handleClick() {
      // 语法：this.$emit('事件名', 参数1, 参数2, ...)
      this.$emit('my-event', '传递的数据');
    }
  },
  template: `<button @click="handleClick">触发事件</button>`
}

第二步：父组件监听事件

// 方式1：直接在模板中处理
<child-component @my-event="message = $event"></child-component>

// 方式2：调用方法处理
<child-component @my-event="handleEvent"></child-component>

methods: {
  handleEvent(data) {
    console.log('接收到：', data);
  }
}

演示效果：

💡 $event 特殊变量

在模板中可以使用 $event 来获取 $emit 传递的第一个参数： 

// 子组件
this.$emit('update-count', 100)

// 父组件模板中
<child @update-count="count = $event"></child>
// $event 的值就是 100

📦 3. 传递多个参数

$emit可以传递多个参数
// 子组件：传递多个参数
this.$emit('user-login', username, password, rememberMe)

// 父组件：接收多个参数
<child @user-login="handleLogin"></child>

methods: {
  handleLogin(username, password, rememberMe) {
    console.log(username, password, rememberMe)
  }
}

传递对象（推荐）

// 子组件：传递对象
this.$emit('user-login', {
  username: 'admin',
  password: '123456',
  rememberMe: true
})

// 父组件：接收对象
methods: {
  handleLogin(userData) {
    console.log(userData.username)
    console.log(userData.password)
  }
}

🖱️ 6. 原生事件 vs 自定义事件

理解.native修饰符
// ❌ 默认情况：组件上的@click是自定义事件
<child-component @click="handleClick"></child-component>
// 需要子组件内部 this.$emit('click') 才会触发

// ✅ 使用.native：监听组件根元素的原生DOM事件
<child-component @click.native="handleClick"></child-component>
// 直接监听组件根元素的点击事件

演示效果：

⚠️ 注意区别
  • 普通HTML元素：@click 是原生DOM事件
  • 组件标签：@click 是自定义事件（需要$emit）
  • 组件标签 + .native：@click.native 是原生DOM事件

🔄 7. props + $emit：完整的双向通信

组合使用实现父子双向通信
父组件（数据管理者）
data: { count: 0 }
⬇️ props传数据下去
⬆️ @event监听事件
⬇️ :count="count" (props)
⬆️ @increment="count++" ($emit)
子组件（UI展示者）
props: ['count']
⬇️ 接收props
⬆️ $emit触发事件 
// 子组件：接收props，触发事件
const Counter = {
  props: ['count'],
  methods: {
    increment() {
      this.$emit('increment');  // 通知父组件增加
    },
    decrement() {
      this.$emit('decrement');  // 通知父组件减少
    }
  },
  template: `
    <div>
      <p>当前值：{{ count }}</p>
      <button @click="increment">+1</button>
      <button @click="decrement">-1</button>
    </div>
  `
}

// 父组件：管理数据，监听事件
<counter 
  :count="count" 
  @increment="count++" 
  @decrement="count--"
></counter>

data() {
  return { count: 0 }
}

演示效果：

✅ 最佳实践
  • 数据归属：数据由父组件管理，子组件只负责展示
  • 单向数据流：props向下传，$emit向上传
  • 职责分离：父组件管理状态，子组件处理交互
  • 可复用性：子组件不依赖父组件具体实现，更易复用
📚 本节知识点总结

核心概念

对比项 props（父→子） $emit（子→父）
作用 父组件向子组件传递数据 子组件向父组件发送消息
类比 函数参数 回调函数
数据流向 父 → 子（向下） 子 → 父（向上）
子组件定义 props: ['value'] this.$emit('event-name')
父组件使用 :value="data" @event-name="handler"
传递数据 通过属性传递 通过事件参数传递

$emit要点

  1. 基本语法：this.$emit('event-name', param1, param2)
  2. 事件命名：推荐使用 kebab-case（短横线）
  3. 传递数据：可以传递多个参数，推荐传递对象
  4. 监听事件：父组件用 @event-name 监听
  5. $event变量：在模板中可用 $event 获取第一个参数
  6. .native修饰符：监听组件根元素的原生DOM事件

完整流程

1. 父组件通过 props 传数据给子组件     (:value="data")
2. 子组件通过 props 接收数据             (props: ['value'])
3. 子组件触发事件通知父组件             (this.$emit('update'))
4. 父组件监听事件并处理                 (@update="handleUpdate")
