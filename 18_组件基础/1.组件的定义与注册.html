🎨 Vue 组件基础

Component - 构建大型应用的基础

📌 1. 全局组件

全局注册的组件可以在任何地方使用
// 定义全局组件
Vue.component('my-button', {
  data() {
    return {
      count: 0
    }
  },
  template: `
    <button @click="count++">
      点击了 {{ count }} 次
    </button>
  `
});

// 使用组件
<my-button></my-button>
<my-button></my-button>  // 每个组件都有独立的 count

💡 全局组件的特点
  • ✅ 可以在任何 Vue 实例或组件中使用
  • ✅ 不需要在 components 中注册
  • ❌ 即使不使用也会被打包（增加代码体积）
  • ⚠️ 适合：基础组件、通用组件（按钮、输入框、图标等）

📌 2. 局部组件

局部注册的组件只能在注册它的实例中使用 
// 定义组件配置对象
const MyCard = {
  data() {
    return {
      title: '用户卡片',
      name: '张三',
      age: 18
    }
  },
  template: `
    <div class="component-demo">
      <h4>{{ title }}</h4>
      <p>姓名：{{ name }}</p>
      <p>年龄：{{ age }}</p>
    </div>
  `
};

// 在 Vue 实例中注册
new Vue({
  el: '#root',
  components: {
    'my-card': MyCard  // 局部注册
  }
});

// 使用组件
<my-card></my-card>

演示效果：

✅ 局部组件的特点（推荐）
  • ✅ 按需加载，减少代码体积
  • ✅ 组件作用域清晰，便于维护
  • ❌ 需要在每个使用它的地方注册
  • ⚠️ 适合：大部分业务组件

🔍 4. 为什么组件的 data 必须是函数？

数据独立性演示
// ❌ 错误示例：data 是对象（会导致数据共享）
Vue.component('counter-bad', {
  data: { count: 0 },  // 所有实例共享同一个 count
  template: '<button @click="count++">{{ count }}</button>'
});

// ✅ 正确示例：data 是函数（每个实例都有独立数据）
Vue.component('counter-good', {
  data() {
    return { count: 0 }  // 每个实例都有自己的 count
  },
  template: '<button @click="count++">{{ count }}</button>'
});

✅ 为什么必须是函数？

原理：组件会被多次复用创建多个实例。

  • 如果 data 是对象 → 所有实例共享同一个对象 → 修改一个会影响其他
  • 如果 data 是函数 → 每次创建实例都调用函数返回新对象 → 数据独立互不影响

📄 5. 组件的 template 选项

模板的写法和注意事项
// 方式1：单行模板
Vue.component('simple-comp', {
  template: '<div>简单组件</div>'
});

// 方式2：多行模板（使用反引号）
Vue.component('complex-comp', {
  template: `
    <div>
      <h3>复杂组件</h3>
      <p>支持多行 HTML</p>
      <button>按钮</button>
    </div>
  `
});

// ⚠️ 注意：模板必须有且只有一个根元素
// ❌ 错误示例
template: `
  <div>第一个根元素</div>
  <div>第二个根元素</div>  // 错误！
`

// ✅ 正确示例
template: `
  <div>
    <div>第一个元素</div>
    <div>第二个元素</div>
  </div>
`

演示效果：

⚠️ template 注意事项
  • ❗ 必须有且只有一个根元素
  • ✅ 推荐使用反引号（`）来写多行模板
  • ✅ 模板中可以使用组件的 data、methods、computed 等
  • ✅ 支持所有 Vue 指令（v-if、v-for、v-bind 等）

🚀 6. 组件使用的完整流程

三步走：定义 → 注册 → 使用

步骤1：定义组件

// 定义组件配置对象
const StudentCard = {
  data() {
    return {
      name: '李四',
      grade: '三年级',
      score: 95
    }
  },
  methods: {
    showInfo() {
      alert(`学生：${this.name}，成绩：${this.score}分`);
    }
  },
  template: `
    <div class="component-demo">
      <h4>学生信息</h4>
      <p>姓名：{{ name }}</p>
      <p>年级：{{ grade }}</p>
      <p>成绩：{{ score }}分</p>
      <button @click="showInfo">查看详情</button>
    </div>
  `
};

步骤2：注册组件（选择全局或局部）

// 方式1：全局注册
Vue.component('student-card', StudentCard);

// 方式2：局部注册
new Vue({
  components: {
    'student-card': StudentCard
  }
});

步骤3：使用组件

<student-card></student-card>

📚 本节知识点总结

核心概念

  • ✅ 组件是可复用的 Vue 实例
  • ✅ 组件的 data 必须是函数（确保数据独立）
  • ✅ 模板必须有且只有一个根元素

两种注册方式

类型 注册方式 使用范围 推荐场景
全局组件 Vue.component() 任何地方 基础组件、通用组件
局部组件 components: {} 注册的实例中 大部分业务组件

使用三步骤

  1. 定义：创建组件配置对象
  2. 注册：全局或局部注册
  3. 使用：在模板中使用组件标签
