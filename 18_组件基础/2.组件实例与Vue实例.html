📊 1. Vue实例（vm）vs 组件实例（vc）

它们是什么关系？

⬇️ 包含

对比项 Vue实例（vm） 组件实例（vc）

✅ 核心理解
  • vm（Vue实例）：应用的根，通过 new Vue() 创建，通常只有一个
  • vc（组件实例）：可复用的Vue实例，由Vue自动创建，可以有多个
  • 关系：vm 是特殊的 Vue 实例，vc 是普通的 Vue 实例，它们都继承自 Vue

🏗️ 2. VueComponent构造函数（了解）

Vue如何创建组件实例？
// 当我们定义组件时
const MyComponent = {
  data() {
    return { msg: 'Hello' }
  },
  template: '<div>{{ msg }}</div>'
};

// Vue 内部会：
// 1. 创建一个新的 VueComponent 构造函数
// 2. 使用这个构造函数创建组件实例（vc）
// 3. vc = new VueComponent(options)

// 注意：我们无法直接访问 VueComponent，它是Vue内部使用的

演示：查看组件实例

打开控制台，点击按钮查看组件实例的详细信息

💡 重要特点
  • ✅ 每次调用组件，Vue都会创建一个新的VueComponent实例
  • ✅ 不同的组件有不同的VueComponent构造函数（即使配置相同）
  • ✅ 我们不需要关心VueComponent的创建，Vue会自动处理
  • ❌ 我们无法直接访问VueComponent构造函数（它是内部实现）

🎯 3. this指向问题（重点掌握）

在组件中，this指向谁？
const MyComponent = {
  data() {
    console.log('data函数中的this:', this);  // vc（组件实例）
    return { count: 0 }
  },
  methods: {
    increment() {
      console.log('methods中的this:', this);  // vc（组件实例）
      this.count++;
    },
    delayIncrement() {
      // ❌ 错误：普通函数中的this会丢失
      setTimeout(function() {
        console.log('定时器中的this:', this);  // window
        this.count++;  // 报错！this不是vc
      }, 1000);
      
      // ✅ 正确：箭头函数继承外层的this
      setTimeout(() => {
        console.log('箭头函数中的this:', this);  // vc（组件实例）
        this.count++;  // 正确
      }, 1000);
    }
  },
  mounted() {
    console.log('生命周期钩子中的this:', this);  // vc（组件实例）
  }
};

演示：this指向

⚠️ this指向的注意事项
  • ✅ Vue管理的函数（data、methods、生命周期等）：this指向vc或vm
  • ❌ 非Vue管理的函数（定时器回调、Ajax回调等）：this可能丢失
  • ✅ 解决方案：使用箭头函数，让this继承外层的vc
  • ❌ 绝对不要：在Vue配置对象中使用箭头函数

🔗 4. 内置关系属性（重点掌握）

组件间如何互相访问？

关系图解：

Root (vm) - this.$root
Parent Component (vc) - this.$parent
Child Component 1 (vc) - this.$children[0]
Child Component 2 (vc) - this.$children[1]

4个重要的内置属性：

属性 说明 用途 注意事项
this.$parent 父组件实例 子组件访问父组件的数据和方法 如果是根实例则为undefined
this.$children 子组件实例数组 父组件访问子组件 不保证顺序，不是响应式
this.$root 根Vue实例 任何组件都可以访问根实例 慎用，会导致耦合
this.$refs 注册了ref的元素/组件 精确访问特定的子组件或DOM 最常用，推荐使用

演示：组件间访问

✅ 最佳实践
  • ⭐ 推荐使用 $refs：明确、可控、最常用
  • ⚠️ 谨慎使用 $parent：会增加组件耦合度
  • ⚠️ 避免使用 $children：顺序不可靠，推荐用$refs
  • ❌ 避免使用 $root：全局状态建议用Vuex

📌 5. $refs的使用（重点掌握）

ref：给元素或组件注册引用
// 在模板中使用 ref
<template>
  <div>
    <!-- 给DOM元素注册ref -->
    <input ref="myInput" type="text">
    
    <!-- 给子组件注册ref -->
    <child-component ref="myChild"></child-component>
    
    <button @click="accessRefs">访问refs</button>
  </div>
</template>

<script>
export default {
  methods: {
    accessRefs() {
      // 访问DOM元素
      console.log(this.$refs.myInput);  // 真实的DOM元素
      this.$refs.myInput.focus();  // 让输入框获得焦点
      
      // 访问子组件实例
      console.log(this.$refs.myChild);  // 子组件的vc实例
      this.$refs.myChild.someMethod();  // 调用子组件的方法
      console.log(this.$refs.myChild.someData);  // 访问子组件的数据
    }
  }
}
</script>

演示：$refs的使用

$refs 的特点：
  • ✅ 可以访问DOM元素或组件实例
  • ✅ 通过 ref 名称精确定位
  • ✅ 只能在 mounted 之后访问（因为需要DOM渲染完成）
  • ❌ 不是响应式的（$refs的改变不会触发视图更新）
  • ⭐ 最常用的组件间通信辅助手段

🔬 6. 原型链关系（了解即可）

组件实例如何继承Vue的功能？
// Vue的原型链设计
VueComponent.prototype.__proto__ === Vue.prototype

// 这意味着：
组件实例(vc) → VueComponent.prototype → Vue.prototype → Object.prototype

// 因此，组件实例可以访问：
1. 自己定义的属性和方法（data、methods）
2. VueComponent原型上的属性和方法
3. Vue原型上的属性和方法（$watch、$emit、$on等）
4. Object原型上的属性和方法
组件实例 (vc)
↓ __proto__ 指向
VueComponent.prototype
↓ __proto__ 指向
Vue.prototype
（这里有 $watch、$emit、$on 等方法）
↓ __proto__ 指向
Object.prototype

演示：原型链验证

💡 为什么要这样设计？

通过让 VueComponent.prototype.__proto__ 指向 Vue.prototype，组件实例就可以：

  • ✅ 使用Vue原型上的所有方法（$watch、$emit、$on等）
  • ✅ 复用Vue的功能，不需要重复实现
  • ✅ 保持组件和Vue实例的一致性

结论：这是Vue内部的实现细节，了解即可，不影响日常使用。

📚 本节知识点总结

核心概念（掌握）

  • Vue实例（vm）：根实例，通过 new Vue() 创建
  • 组件实例（vc）：通过 VueComponent 构造函数自动创建
  • this指向：在组件配置中，this 指向组件实例（vc）

重要属性（熟练掌握）

属性 作用 推荐度
this.$refs 访问子组件或DOM元素 ⭐⭐⭐⭐⭐
this.$parent 访问父组件 ⭐⭐⭐
this.$root 访问根实例 ⭐⭐
this.$children 访问子组件数组 ⭐

关键要点（牢记）

  1. Vue管理的函数用普通函数，非Vue管理的函数用箭头函数
  2. $refs 是最常用的组件访问方式
  3. 组件的data必须是函数（确保每个实例数据独立）
  4. 组件实例可以使用Vue原型上的所有方法
