Vuex · State 与 Getters

26-2  |  State 读取 / mapState / Getters 派生 / mapGetters / 与 computed 对比

第一节

State — 单一状态树

Vuex 用单一状态树管理所有共享状态，即整个应用只有一个 Store 实例。State 里存放的数据和 Vue 组件的 data 一样是响应式的——State 变化时，依赖它的组件自动更新。

在 store 中定义 State
// store/index.js const store = new Vuex.Store({ state: { // 基本类型 count: 0, isLoading: false, username: '', // 数组 cartItems: [], notifications: [], // 对象 user: { id: null, name: '', avatar: '', roles: [] }, // 枚举类型（字符串） theme: 'light', // 'light' | 'dark' locale: 'zh-CN' } })
⚠️ State 必须提前声明所有属性！
和 Vue 2 data 一样，State 里没有声明的属性不是响应式的，后续添加的属性视图不会更新。
如果确实需要动态添加属性，使用 Vue.set(state.obj, 'newKey', value)。
第二节

读取 State 的三种方式

方式1：直接读取（冗长，但直观）
// 组件中 computed: { count() { return this.$store.state.count }, username() { return this.$store.state.username }, cartItems(){ return this.$store.state.cartItems } } // 模板中 <p>当前用户：{{ $store.state.username }}</p> <p>购物车：{{ $store.state.cartItems.length }} 件</p>
方式2：mapState 辅助函数（推荐）

mapState 自动生成 computed 属性，大幅减少重复代码：

import { mapState } from 'vuex' export default { computed: { // 数组写法：属性名和 state 键名相同 ...mapState(['count', 'username', 'cartItems']), // 对象写法：属性名和 state 键名不同，或需要额外处理 ...mapState({ num: 'count', // 字符串，映射 state.count user: state => state.user, // 函数，可以做额外处理 countPlusLocal(state) { // 可以使用 this 访问组件实例 return state.count + this.localCount } }), // 组件自己的 computed 也可以混用 localComputed() { return this.someLocalData * 2 } } }
方式3：在 setup()中使用（Vue 2.7 / Composition API）
import { computed } from 'vue' import { useStore } from 'vuex' export default { setup() { const store = useStore() const count = computed(() => store.state.count) return { count } } }
第三节

Getters — 从 State 派生数据

Getters 就像 Store 的计算属性，基于 State 派生出新数据，并且有缓存（State 不变则返回缓存值）。

定义 Getters
getters: { // 参数1：state；参数2：其他 getters（可选） cartCount(state) { return state.cartItems.length }, // 基于 state 过滤 doneTaskCount(state) { return state.tasks.filter(t => t.done).length }, // 引用其他 getter cartTotal(state, getters) { return state.cartItems.reduce((sum, i) => sum + i.price * i.qty, 0) }, // 返回函数（用于带参数的查询，注意：返回函数时不缓存） getArticleById: (state) => (id) => { return state.articles.find(a => a.id === id) }, // 结合 user 对象判断权限 isLoggedIn(state) { return !!state.user.id }, isAdmin(state) { return state.user.roles.includes('admin') } }
在组件中使用 Getters
// 直接读 computed: { cartCount() { return this.$store.getters.cartCount }, isAdmin() { return this.$store.getters.isAdmin } } // 带参数的 getter（返回函数） computed: { article() { return this.$store.getters.getArticleById(this.articleId) } }
mapGetters 辅助函数
import { mapGetters } from 'vuex' computed: { // 数组：属性名和 getter 名相同 ...mapGetters(['cartCount', 'cartTotal', 'isLoggedIn', 'isAdmin']), // 对象：重命名 ...mapGetters({ total: 'cartTotal', // 本地叫 total，对应 getter 叫 cartTotal loggedIn: 'isLoggedIn' }) }
第四节

State vs Getters：什么时候用哪个

场景用 State 还是 Getter
直接存储原始数据（用户ID、token、列表数据）State
数组的 length（如购物车件数）Getter
数组过滤（如"已完成的任务"）Getter
数组汇总（如"购物车总价"）Getter
从 state 派生的布尔值（如 isLoggedIn = !!user.id）Getter
根据 ID 查找某条数据Getter（返回函数）
对比：不用 Getter vs 用 Getter
❌ 不用 Getter（每个组件重复写）
// 组件A computed: { total() { return this.$store.state.cartItems .reduce((s, i) => s + i.price, 0) } } // 组件B 也要写一遍同样的代码
✅ 用 Getter（一处定义，多处复用）
// store/index.js getters: { cartTotal(state) { return state.cartItems .reduce((s,i)=>s+i.price, 0) } } // 所有组件：this.$store.getters.cartTotal
📌 Getter 和组件 computed 的对比：
• 组件 computed：只在该组件内使用的计算属性
• Vuex getter：需要在多个组件中共用的计算逻辑
原则：如果只有一个组件用得到，直接写在组件的 computed 里；多个组件都需要，放到 Getter 里。
第五节

完整示例：购物车状态管理

// store/index.js state: { cartItems: [ // { id, name, price, qty } ], user: { id: null, name: '' } }, getters: { // 购物车件数（显示在导航栏角标） cartCount: state => state.cartItems.reduce((n, i) => n + i.qty, 0), // 购物车总价 cartTotal: state => state.cartItems.reduce((sum, i) => sum + i.price * i.qty, 0), // 是否已登录 isLoggedIn: state => !!state.user.id, // 某商品是否已在购物车（带参数） isInCart: state => id => state.cartItems.some(i => i.id === id) }
// NavBar.vue — 显示购物车数量角标 import { mapGetters } from 'vuex' computed: { ...mapGetters(['cartCount', 'isLoggedIn']) } // 模板 <span class="badge" v-if="cartCount > 0">{{ cartCount }}</span> // CartPage.vue — 显示明细和总价 import { mapState, mapGetters } from 'vuex' computed: { ...mapState(['cartItems']), ...mapGetters(['cartTotal', 'cartCount']) }
