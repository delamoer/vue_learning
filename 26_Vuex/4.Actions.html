第一节

Actions vs Mutations

对比项MutationAction
调用方式commit('MUTATION', payload)dispatch('action', payload)
是否允许异步❌ 必须同步✅ 可以异步（async/await、Promise）
直接修改 State?✅ 是，直接修改❌ 不行，通过 commit Mutation 间接修改
DevTools 追踪每次 commit 都记录快照记录 dispatch/完成，快照由 Mutation 触发
典型场景简单赋值、数组增删API 请求、定时器、多步骤操作
⭐ 简单规则：涉及异步（axios、setTimeout、Promise）→ 必须用 Action；只是改数据、没有副作用 → 直接 commit Mutation 即可，不需要绕一圈 Action。
第二节

Action 的 context 对象

Action 函数接收一个叫 context 的对象，它包含和 Store 实例一样的属性：

actions: { // 完整写法 myAction(context) { context.state // 等同于 store.state context.getters // 等同于 store.getters context.commit // 等同于 store.commit context.dispatch // 等同于 store.dispatch（调用其他 action） context.rootState // 模块内访问根 state（模块化时使用） context.rootGetters // 模块内访问根 getters（模块化时使用） }, // 解构写法（实践中最常用） login({ commit, state, dispatch }, credentials) { // 直接拿到需要的方法，代码更简洁 commit('SET_LOADING', true) } }
📌 context 解构是最佳实践：只解构你用到的部分，代码更清晰。
{ commit }：只提交 mutation  |  { commit, dispatch }：还需要调用其他 action  |  { state, commit }：还需要读状态
第三节

dispatch 分发 Action

基本用法（在组件中）
// 普通写法 this.$store.dispatch('login', { username: 'Alice', password: '123456' }) // 对象写法 this.$store.dispatch({ type: 'login', username: 'Alice', password: '123456' }) // dispatch 返回 Promise，可以 await async handleLogin() { try { await this.$store.dispatch('login', this.form) // 登录成功，跳转 this.$router.push('/dashboard') } catch (err) { // 登录失败，显示错误 this.errorMsg = err.message } }
第四节

Action 处理异步操作

典型模式：async/await + try/catch
actions: { // 登录：调用 API → 成功存 token + 用户 → 失败抛错误 async login({ commit }, { username, password }) { commit('SET_LOADING', true) try { const { data } = await axios.post('/api/login', { username, password }) commit('SET_TOKEN', data.token) commit('SET_USER', data.user) return data.user // 组件 dispatch('login') 的 .then() 可拿到 } catch (error) { commit('SET_TOKEN', '') throw error // 继续向上抛，组件 .catch() 可处理 } finally { commit('SET_LOADING', false) } }, // 获取商品列表（带分页参数） async fetchProducts({ commit }, { page = 1, pageSize = 20 } = {}) { const { data } = await axios.get('/api/products', { params: { page, pageSize } }) commit('SET_PRODUCTS', data.list) commit('SET_TOTAL', data.total) }, // 购物车：检查库存 → 加入购物车 async addToCart({ commit, state }, product) { const alreadyInCart = state.cartItems.some(i => i.id === product.id) if (alreadyInCart) { commit('INCREMENT_QTY', product.id) return } const { data } = await axios.get(`/api/products/${product.id}/stock`) if (data.stock > 0) { commit('ADD_TO_CART', product) } else { throw new Error('该商品库存不足') } } }
✅ Action 返回 Promise 的意义：
dispatch() 本质上返回 Action 函数的返回值（包装成 Promise）。
用 async Action 意味着组件可以 await dispatch()，在 Action 完成后做跳转、提示等。
第五节

Actions 之间相互调用

actions: { // fetchCart 依赖先加载用户信息 async initApp({ dispatch }) { await dispatch('fetchUser') // 先获取用户 await dispatch('fetchCart') // 再获取购物车 dispatch('fetchNotifications') // 通知可以并行，不用 await }, async fetchUser({ commit }) { const { data } = await axios.get('/api/user') commit('SET_USER', data) }, async fetchCart({ commit, state }) { if (!state.user) return // 未登录不加载 const { data } = await axios.get(`/api/cart/${state.user.id}`) commit('SET_CART', data.items) }, // 并行调用多个 Action async fetchDashboard({ dispatch }) { await Promise.all([ dispatch('fetchOrders'), dispatch('fetchStats'), dispatch('fetchNotifications') ]) // 三个请求并发，全部完成后才继续 } }
第六节

mapActions 辅助函数

import { mapActions } from 'vuex' methods: { // 数组写法 ...mapActions([ 'login', // this.login(payload) → this.$store.dispatch('login', payload) 'logout', 'fetchProducts' ]), // 对象写法（重命名） ...mapActions({ doLogin: 'login', // this.doLogin(payload) → dispatch('login', payload) doLogout: 'logout' }), // 使用时和普通方法一样，可以传参、await async handleLogin() { try { await this.login(this.form) this.$router.push('/dashboard') } catch(err) { this.error = err.message } } }
