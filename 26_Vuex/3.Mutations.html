第一节

Mutation 是什么

Mutation 是 Vuex 中唯一合法修改 State 的方式。它是一个函数，接收 state 作为第一参数，在函数体内直接修改 state。

必须是同步函数 — Vuex DevTools 会记录每次 Mutation 前后的 State 快照，异步操作无法快照（用 Action 处理异步）。

定义 Mutation
mutations: { // 最简单的 mutation（无载荷） INCREMENT(state) { state.count++ }, RESET_COUNT(state) { state.count = 0 }, // 带载荷（payload）的 mutation SET_COUNT(state, payload) { state.count = payload // payload 是原始值 }, SET_USER(state, user) { state.user = user // payload 是对象 }, ADD_TO_CART(state, item) { const found = state.cartItems.find(i => i.id === item.id) if (found) { found.qty++ // 已存在：数量+1 } else { state.cartItems.push({ ...item, qty: 1 }) } }, REMOVE_FROM_CART(state, itemId) { state.cartItems = state.cartItems.filter(i => i.id !== itemId) }, CLEAR_CART(state) { state.cartItems = [] } }
第二节

提交 Mutation（commit）

普通写法
// this.$store.commit('MUTATION_NAME', payload) this.$store.commit('INCREMENT') this.$store.commit('SET_COUNT', 10) this.$store.commit('SET_USER', { id: 1, name: 'Alice' }) this.$store.commit('ADD_TO_CART', { id: 42, name: '商品A', price: 99 })
对象提交方式（载荷信息更完整）
// commit({ type, ...payload }) this.$store.commit({ type: 'ADD_TO_CART', id: 42, name: '商品A', price: 99 }) // 此时 mutation 接收到的 payload 是整个对象（包含 type） ADD_TO_CART(state, payload) { // payload = { type: 'ADD_TO_CART', id: 42, name: '商品A', price: 99 } state.cartItems.push(payload) }
mapMutations 辅助函数
import { mapMutations } from 'vuex' methods: { // 数组写法：生成同名方法 ...mapMutations([ 'INCREMENT', // this.INCREMENT() → this.$store.commit('INCREMENT') 'RESET_COUNT', 'CLEAR_CART' ]), // 对象写法：重命名 ...mapMutations({ add: 'INCREMENT', // this.add() → this.$store.commit('INCREMENT') reset: 'RESET_COUNT' }), // 使用时可以直接传载荷 handleAdd() { this.ADD_TO_CART({ id: 1, name: '商品', price: 99 }) } }
第三节

Mutation 类型常量（推荐做法）

用字符串的 Mutation 名称容易拼写错误，且无法享受编辑器自动补全。推荐将 Mutation 类型提取为常量：

// store/mutation-types.js export const INCREMENT = 'INCREMENT' export const RESET_COUNT = 'RESET_COUNT' export const SET_USER = 'SET_USER' export const SET_TOKEN = 'SET_TOKEN' export const CLEAR_USER = 'CLEAR_USER' export const ADD_TO_CART = 'ADD_TO_CART' export const REMOVE_FROM_CART = 'REMOVE_FROM_CART' export const CLEAR_CART = 'CLEAR_CART'
// store/index.js import * as types from './mutation-types' mutations: { // 用计算属性名语法 [types.XXX] [types.INCREMENT](state) { state.count++ }, [types.SET_USER](state, user) { state.user = user }, [types.ADD_TO_CART](state, item) { state.cartItems.push(item) } }
// 组件中提交 import { ADD_TO_CART } from '@/store/mutation-types' methods: { addToCart(item) { this.$store.commit(ADD_TO_CART, item) // 常量名错误 → 编辑器/编译器会报错，而不是运行时默默失效 } }
⭐ 为什么 Mutation 名约定全大写？
全大写是社区约定（类似 Redux 的 action type），一眼就能区分"这是 Mutation 提交"而不是普通方法调用。小型项目可以不这么做，但大型项目建议遵守。
第四节

Mutation 中的响应式规则

Vuex 的 State 遵循 Vue 2 的响应式规则，有一些操作不会触发视图更新：

❌ 不是响应式的操作
// ❌ 直接给对象添加新属性（不响应式） WRONG_ADD(state, { key, value }) { state.obj[key] = value // 视图不更新！ } // ❌ 直接给数组赋值（某些情况） WRONG_SPLICE(state, index) { state.arr[index] = 'new' // 视图不更新！ // delete state.arr[index] // 也不响应！ }
✅ 正确做法
// ✅ 给对象添加新属性：Vue.set 或对象展开 import Vue from 'vue' ADD_OBJ_PROP(state, { key, value }) { Vue.set(state.obj, key, value) // 响应式添加 // 或者： state.obj = { ...state.obj, [key]: value } // 替换整个对象 } // ✅ 修改数组元素：Vue.set 或 splice UPDATE_ITEM(state, { index, value }) { Vue.set(state.arr, index, value) // 响应式修改 // 或： state.arr.splice(index, 1, value) // splice 是响应式的 } // ✅ 删除对象属性：Vue.delete DEL_OBJ_PROP(state, key) { Vue.delete(state.obj, key) } // ✅ 数组响应式方法（这些都能触发更新） // push / pop / shift / unshift / splice / sort / reverse state.arr.push(item) state.arr.splice(index, 1) state.arr = state.arr.filter(i => i.id !== id) // filter 返回新数组，响应式
⚠️ Vue 2 响应式系统的两个经典限制：
1. 对象新增属性不响应 → 用 Vue.set() 或替换整个对象
2. 数组下标赋值不响应 → 用 Vue.set() 或 splice()
Vue 3 用 Proxy 解决了这两个问题，这是 Vue 2 特有的坑。
第五节

实战：用户登录/登出完整 Mutation 设计

// store/mutation-types.js export const SET_USER = 'SET_USER' export const SET_TOKEN = 'SET_TOKEN' export const CLEAR_AUTH = 'CLEAR_AUTH' export const SET_LOADING = 'SET_LOADING'
// store/index.js state: { user: null, token: localStorage.getItem('token') || '', // 从本地存储恢复 isLoading: false }, mutations: { // 登录成功：存储用户和 token [types.SET_USER](state, user) { state.user = user }, [types.SET_TOKEN](state, token) { state.token = token localStorage.setItem('token', token) // 持久化 }, // 登出：清空用户信息 [types.CLEAR_AUTH](state) { state.user = null state.token = '' localStorage.removeItem('token') }, // 全局 loading 状态 [types.SET_LOADING](state, loading) { state.isLoading = loading } }, // action 里统一调用多个 mutation（异步操作） actions: { async login({ commit }, credentials) { commit(types.SET_LOADING, true) try { const { token, user } = await api.login(credentials) commit(types.SET_TOKEN, token) commit(types.SET_USER, user) } finally { commit(types.SET_LOADING, false) } }, logout({ commit }) { commit(types.CLEAR_AUTH) } }
