🚀 2. 初始化阶段详解

从 new Vue() 到 mounted 的过程

beforeCreate（创建前）- 最早的钩子

new Vue({
  beforeCreate() {
    console.log('1️⃣ beforeCreate - 实例尚未初始化');
    console.log('data:', this.data);        // undefined
    console.log('methods:', this.methods);  // undefined
    console.log('$el:', this.$el);          // undefined
  }
});
此时的状态：
  • ❌ 无法访问 data
  • ❌ 无法访问 methods
  • ❌ 无法访问计算属性
  • ❌ 无法访问 $el
  • ✅ 实例刚好被创建

created（创建后）- 数据初始化完成

new Vue({
  data() {
    return { count: 0 }
  },
  created() {
    console.log('2️⃣ created - 实例已初始化');
    console.log('this.count:', this.count);    // 0
    console.log('$el:', this.$el);              // undefined（DOM 还未挂载）
    
    // 这里适合做：
    // - 初始化数据
    // - 发送 Ajax 请求
    // - 设置事件监听
  }
});
此时的状态：
  • ✅ 数据已初始化
  • ✅ 可访问 methods 和计算属性
  • ✅ 可访问响应式数据
  • ❌ DOM 未挂载（$el 为 undefined）
  • ❌ 页面还看不到内容

beforeMount（挂载前）- 模板编译完成

new Vue({
  beforeMount() {
    console.log('3️⃣ beforeMount - 页面即将挂载');
    console.log('html:', this.$el.innerHTML);  // 原始 HTML（未编译）
    console.log('data:', this.message);        // ✅ 可以访问
    
    // 此时虚拟 DOM 已创建，但未转换为真实 DOM
  }
});
此时的状态：
  • ✅ 虚拟 DOM 已创建
  • ✅ 可访问所有数据
  • ⚠️ 真实 DOM 还未生成
  • ❌ 页面还看不到内容

mounted（挂载后）- 最常用的钩子

new Vue({
  mounted() {
    console.log('4️⃣ mounted - 页面已挂载到 DOM');
    console.log('$el:', this.$el);                    // ✅ 可以访问真实 DOM
    console.log('html:', this.$el.innerHTML);        // ✅ 可以看到编译后的 HTML
    console.log('dom elements:', this.$refs);        // ✅ 可以访问 ref 元素
    
    // 这里最适合做：
    // - DOM 操作
    // - 初始化 jQuery、echarts 等第三方库
    // - 为 DOM 添加事件监听
  }
});
此时的状态：
  • ✅ 真实 DOM 已挂载
  • ✅ $el 可用
  • ✅ 可以进行所有 DOM 操作
  • ✅ 第三方库初始化的最佳时机
  • ✅ 页面已完全渲染

🔄 3. 更新阶段详解

响应式数据变化触发的两个钩子

beforeUpdate（更新前）- 数据变了，页面还没变

new Vue({
  data() {
    return { count: 0 }
  },
  beforeUpdate() {
    console.log('beforeUpdate - 数据已变，但 DOM 未更新');
    console.log('this.count:', this.count);          // ✅ 新值
    console.log('DOM 中显示的值:', this.$el.innerHTML);  // ❌ 旧值
    
    // 可以在这里检查将要进行什么改动
    // 但不要修改数据（会导致死循环）
  }
});
此时的状态：
  • ✅ 响应式数据已更新
  • ✅ 计算属性已重算
  • ❌ DOM 还未更新
  • ❌ 页面看不到新值
  • ⚠️ 不要修改数据（会导致死循环）

updated（更新后）- 数据和页面都已更新

new Vue({
  data() {
    return { count: 0 }
  },
  updated() {
    console.log('updated - 页面已更新');
    console.log('this.count:', this.count);          // ✅ 新值
    console.log('DOM 中显示的值:', this.$el.innerHTML);  // ✅ 新值
    
    // 这里可以进行依赖于 DOM 的操作
    // 但仍然要小心，避免修改数据导致死循环
  }
});
此时的状态：
  • ✅ 响应式数据已更新
  • ✅ DOM 已重新渲染
  • ✅ 页面显示最新值
  • ✅ 可以进行 DOM 相关操作
  • ⚠️ 避免修改数据

🗑️ 4. 销毁阶段详解

清理资源的最后时刻

beforeDestroy（销毁前）- 最后的清理机会

new Vue({
  mounted() {
    // 添加事件监听
    this.handleResize = () => console.log('窗口大小改变');
    window.addEventListener('resize', this.handleResize);
  },
  beforeDestroy() {
    console.log('beforeDestroy - 关键！应该在这里清理资源');
    
    // ✅ 移除事件监听
    window.removeEventListener('resize', this.handleResize);
    
    // ✅ 清理定时器
    clearInterval(this.timer);
    clearTimeout(this.timeout);
    
    // ✅ 取消 Ajax 请求
    if (this.request) {
      this.request.cancel();
    }
    
    // ✅ 销毁第三方库
    if (this.chart) {
      this.chart.dispose();  // echarts
    }
    
    // 此时实例仍然完全可用
  }
});
此时的状态：
  • ✅ 实例仍然完全可用
  • ✅ 所有数据和方法仍可访问
  • ✅ 最后的清理机会
  • ❌ 即将销毁

destroyed（销毁后）- 一切已断开连接

new Vue({
  destroyed() {
    console.log('destroyed - 实例已销毁');
    
    // ❌ 所有事件监听都应该已移除
    // ❌ 所有定时器都应该已清理
    // ❌ Vue 实例与 DOM 的连接已断开
    // ❌ 响应式系统已停止工作
  }
});
此时的状态：
  • ✅ 实例已销毁
  • ❌ 响应式数据已移除
  • ❌ 所有事件监听已移除
  • ❌ 不应该再修改数据

📋 5. 常见操作在生命周期的最佳位置

来看看各个常见操作应该放在哪个钩子里
常见操作 最佳位置 备用位置 说明
初始化数据 created beforeCreate（很少用） 数据已初始化，可立即使用
发送 Ajax created 或 mounted - created 更早获得数据；mounted 确保 DOM 就绪
DOM 操作 mounted 或 updated - 需要真实 DOM，不能在 created
第三方库初始化 mounted - 如 echarts、swiper，需要真实 DOM
事件监听添加 mounted - 需要真实 DOM 对象
事件监听移除 beforeDestroy - 防止内存泄漏
定时器清理 beforeDestroy - 必须清理，否则会继续运行
取消 Ajax 请求 beforeDestroy - 避免请求完成后数据混乱
✅ 最常用的组合
// 最常见的使用模式
new Vue({
  data() {
    return { items: [] }
  },
  
  created() {
    // 1. 发送 Ajax 获取数据
    this.fetchData();
  },
  
  mounted() {
    // 2. 初始化第三方库
    this.initChart();
    
    // 3. 添加事件监听
    window.addEventListener('resize', this.handleResize);
  },
  
  beforeDestroy() {
    // 4. 清理资源
    window.removeEventListener('resize', this.handleResize);
    if (this.chart) {
      this.chart.dispose();
    }
  },
  
  methods: {
    fetchData() { /* ... */ },
    initChart() { /* ... */ },
    handleResize() { /* ... */ }
  }
});

💡 7. 完整实战案例：用户列表组件

演示生命周期在真实项目中的应用
// 完整的用户列表组件
new Vue({
  el: '#user-list',
  data() {
    return {
      users: [],
      loading: false,
      error: null,
      page: 1
    }
  },
  
  // 【初始化阶段】
  created() {
    console.log('created: 初始化组件');
    // 1. 第一次加载数据
    this.fetchUsers();
    // 2. 添加全局滚动监听（分页）
    this.handleScroll = this.onWindowScroll.bind(this);
  },
  
  mounted() {
    console.log('mounted: 挂载完成');
    // 1. 添加滚动事件监听（需要真实 DOM）
    window.addEventListener('scroll', this.handleScroll);
    // 2. 初始化第三方库
    this.initTooltip();
  },
  
  // 【更新阶段】
  beforeUpdate() {
    console.log('beforeUpdate: 数据即将更新，记录当前状态');
    // 可以保存滚动位置、焦点等
  },
  
  updated() {
    console.log('updated: 页面已更新');
    // 可以进行 DOM 相关的操作
    // 注意：不要修改数据，会导致死循环
  },
  
  // 【销毁阶段】
  beforeDestroy() {
    console.log('beforeDestroy: 清理资源');
    // 1. 移除事件监听 ✅
    window.removeEventListener('scroll', this.handleScroll);
    // 2. 取消 Ajax 请求 ✅
    if (this.fetchRequest) {
      this.fetchRequest.cancel();
    }
    // 3. 清理定时器 ✅
    clearTimeout(this.timer);
    // 4. 销毁第三方库 ✅
    this.tooltip && this.tooltip.dispose();
  },
  
  methods: {
    async fetchUsers() {
      try {
        this.loading = true;
        // 模拟 Ajax 请求
        let response = await fetch(`/api/users?page=${this.page}`);
        this.users = await response.json();
        this.error = null;
      } catch (err) {
        this.error = err.message;
      } finally {
        this.loading = false;
      }
    },
    
    onWindowScroll() {
      // 检查是否滚动到底部，如果是，加载更多
      if (this.isScrollAtBottom()) {
        this.page++;
        this.fetchUsers();
      }
    },
    
    isScrollAtBottom() {
      return window.innerHeight + window.scrollY >= document.body.offsetHeight;
    },
    
    initTooltip() {
      // 初始化 Tooltip、Popover 等
    }
  }
});
这个案例展示了：
  • created：初始化数据、第一次 Ajax 请求
  • mounted：添加 DOM 事件、初始化第三方库
  • beforeDestroy：移除监听、取消请求、清理定时器

⚠️ 8. 常见注意事项和陷阱

避免在生命周期中踩坑

❌ 陷阱 1：在 updated 中修改数据导致死循环

// ❌ 错误示例：会导致死循环！
new Vue({
  data() {
    return { count: 0 }
  },
  updated() {
    this.count++;  // ❌ 修改数据 -> 触发更新 -> 再次执行 updated -> 再次修改数据...
  }
});
如何修复？
// ✅ 正确做法1：改用 watch
watch: {
  count() {
    // 响应式地处理数据变化
  }
}

// ✅ 正确做法2：设置标志位防止重复
updated() {
  if (!this.isUpdating) {
    this.isUpdating = true;
    // 做一些 DOM 操作
  }
}

❌ 陷阱 2：在 beforeDestroy 中忘记清理资源

// ❌ 错误示例：会导致内存泄漏
new Vue({
  mounted() {
    // 添加事件监听
    window.addEventListener('resize', this.handleResize);
    // 创建定时器
    this.timer = setInterval(() => {
      // 每秒执行
    }, 1000);
  }
  // ❌ 没有在 beforeDestroy 中清理！
});
如何修复？
// ✅ 正确做法：在 beforeDestroy 中清理
beforeDestroy() {
  // 移除事件监听
  window.removeEventListener('resize', this.handleResize);
  // 清理定时器
  clearInterval(this.timer);
}

❌ 陷阱 3：在 created 中尝试访问 DOM

// ❌ 错误示例：DOM 还未挂载
new Vue({
  created() {
    // ❌ $el 是 undefined
    const el = this.$el;
    // ❌ 无法访问 ref
    this.$refs.input.focus();
  }
});
如何修复？
// ✅ 正确做法：使用 mounted 或 $nextTick
mounted() {
  // ✅ $el 已可用
  const el = this.$el;
  // ✅ 可以访问 ref
  this.$refs.input.focus();
}

// 或在 created 中使用 $nextTick
created() {
  this.$nextTick(() => {
    // 这里 DOM 已准备好
    this.$refs.input.focus();
  });
}

❌ 陷阱 4：在 mounted 中进行大量同步操作

// ❌ 不推荐：会阻塞主线程
new Vue({
  mounted() {
    // ❌ 这会冻结页面
    for (let i = 0; i < 1000000; i++) {
      this.processData();
    }
  }
});
如何修复？
// ✅ 使用异步方式
mounted() {
  // 方案1：使用 setTimeout 分块处理
  setTimeout(() => {
    this.processLargeData();
  }, 0);
  
  // 方案2：使用 Worker
  const worker = new Worker('worker.js');
  worker.postMessage(this.data);
}

📚 关键要点总结

3 个阶段 8 个钩子

初始化 beforeCreate → created → beforeMount → mounted
更新 beforeUpdate → updated
销毁 beforeDestroy → destroyed

两个最常用的钩子

  • created ⭐⭐⭐⭐⭐
    • ✅ 数据初始化
    • ✅ 发送 Ajax 请求
    • ✅ 添加全局事件监听
  • mounted ⭐⭐⭐⭐⭐
    • ✅ DOM 操作
    • ✅ 初始化第三方库
    • ✅ 添加 DOM 事件监听

关键规则

  • ✅ created：可以访问数据但不能访问 DOM
  • ✅ mounted：可以访问 DOM
  • ✅ beforeDestroy：一定要清理资源
  • ❌ 不要在 updated 中修改数据→死循环
  • ❌ 不要忘记清理事件监听→内存泄漏
