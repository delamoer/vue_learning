## 🏗️ 项目结构

```
任务管理系统
├── 全局资源
│   ├── 自定义指令（v-focus）
│   ├── 过滤器（formatTime）
│   └── 全局事件总线（eventBus）
│
└── 组件结构
    └── TodoApp（根组件）
        ├── TodoHeader（头部 - 添加任务）
        ├── TodoFilter（筛选器 - 全部/进行中/已完成）
        ├── TodoList（列表容器）
        │   └── TodoItem（任务项组件）× N
        └── TodoFooter（底部 - 统计信息）
```

### 数据流向图
```
TodoApp (tasks数组)
    ↓ props
TodoHeader → emit → TodoApp (添加任务)
TodoFilter → emit → TodoApp (切换筛选)
TodoList
    ↓ props
TodoItem → emit → TodoList → emit → TodoApp (编辑/删除/切换)

特殊通信：
TodoFilter (全选) → eventBus → TodoApp (全选/全不选)
```

### 1. 添加任务
**涉及知识点**：数据绑定、事件处理、收集表单数据、自定义事件

```javascript
// TodoHeader组件
addTask() {
    const newTask = {
        id: Date.now(),
        title: this.taskTitle,
        completed: false,
        priority: this.priority,
        createTime: Date.now()
    };
    this.$emit('add-task', newTask); // 子→父通信
}
```

### 3. 任务筛选
**涉及知识点**：计算属性、列表过滤、绑定样式

```javascript
computed: {
    filteredTasks() {
        switch(this.currentFilter) {
            case 'active':
                return this.tasks.filter(t => !t.completed);
            case 'completed':
                return this.tasks.filter(t => t.completed);
            default:
                return this.tasks;
        }
    }
}
```

### 4. 全选功能
**涉及知识点**：计算属性（get/set）、全局事件总线

```javascript
// TodoFilter组件
computed: {
    allChecked: {
        get() {
            return this.tasks.every(t => t.completed);
        },
        set(value) {
            eventBus.$emit('toggle-all', value); // 全局事件总线
        }
    }
}

// TodoApp组件
mounted() {
    eventBus.$on('toggle-all', this.toggleAll);
}
```

### 5. 数据持久化
**涉及知识点**：监视属性、生命周期钩子、深度监视

```javascript
// 监视任务变化，自动保存
watch: {
    tasks: {
        handler(newTasks) {
            localStorage.setItem('vue-tasks', JSON.stringify(newTasks));
        },
        deep: true // 深度监视数组内对象的变化
    }
}

// 页面加载时恢复数据
mounted() {
    const saved = localStorage.getItem('vue-tasks');
    if (saved) {
        this.tasks = JSON.parse(saved);
    }
}
```

### 6. 统计信息
**涉及知识点**：计算属性、过滤器

```javascript
computed: {
    totalCount() {
        return this.tasks.length;
    },
    completedCount() {
        return this.tasks.filter(t => t.completed).length;
    },
    completionRate() {
        return Math.round((this.completedCount / this.totalCount) * 100) + '%';
    }
}
```

## 🐛 常见问题

### Q1：为什么刷新后数据还在？
**A**：使用了 localStorage 持久化存储。watch 监视 tasks 数组变化，自动保存到本地存储。

### Q2：全选功能为什么用事件总线？
**A**：展示跨组件通信方式。TodoFilter 组件需要通知 TodoApp 组件，但它们不是直接的父子关系，使用事件总线更方便。

### Q3：为什么编辑时输入框会自动聚焦？
**A**：使用了自定义指令 `v-focus`，在元素插入和更新时自动调用 `el.focus()`。

### Q4：计算属性的 get/set 是什么意思？
**A**：
- **get**：读取时调用（显示全选状态）
- **set**：修改时调用（点击全选触发）

### Q5：为什么要用 deep: true 深度监视？
**A**：tasks 是对象数组，修改内部对象的属性（如 `task.completed = true`）时，需要深度监视才能检测到变化。
