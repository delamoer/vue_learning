# VueAdmin 后台管理系统

这是基于 Vue2 + MyUI 组件库实现的后台管理系统完整版。

## ✨ 已实现功能

### 页面布局
- ✅ 侧边栏菜单（仪表盘 / 用户管理 / 订单管理 / 系统设置）
- ✅ 顶栏搜索与实时时间显示
- ✅ 响应式布局（支持移动端）

### 数据概览
- ✅ 统计卡片（总用户、活跃用户、今日新增、待审核）
- ✅ 实时数据计算

### 用户管理

- ✅ 关键字搜索（支持姓名、邮箱）
- ✅ 新增用户（带表单校验与错误抖动动画）

- ✅ 删除用户（带二次确认弹窗）

### 交互动画
- ✅ 按钮悬停/点击动画
- ✅ 卡片悬停上浮效果
- ✅ 对话框缩放进入/离开动画
- ✅ 表单错误抖动提示

## 🛠 技术亮点

### MyUI 组件增强
本次开发中对 MyUI Table 组件进行了**重要升级**：

#### Table 组件支持作用域插槽
```javascript
// 原来：只能显示文本
<my-table-column prop="name" label="姓名"></my-table-column>

// 现在：可以自定义单元格内容
<my-table-column label="操作">
    <template v-slot="{ row }">
        <my-button @click="handleEdit(row)">编辑</my-button>
        <my-button @click="handleDelete(row)">删除</my-button>
    </template>
</my-table-column>
```

**实现方式：**
- 将 Table 组件从模板语法改为 render 函数
- 支持在列配置中传递作用域插槽
- 动态渲染单元格内容（文本或组件）

### 表单双向校验
- 新增和编辑共用同一套校验规则
- 支持必填、长度、邮箱格式等验证
- 自定义验证器（状态字段）
