# 🎨 MyUI 组件库动画效果文档

> 为 MyUI 组件库添加的动画效果详细说明

## ✨ 动画效果总览

### 1. Button 按钮 - 悬停与点击动画

#### 添加的效果：
- ✅ **悬停抬起**：鼠标悬停时按钮上浮 2px
- ✅ **阴影渐变**：悬停时显示柔和的阴影
- ✅ **点击反馈**：点击时轻微缩放，增强交互感
- ✅ **流畅过渡**：使用 cubic-bezier 缓动函数

#### 技术细节：
```css
.my-button {
    transition: all 0.3s cubic-bezier(0.645, 0.045, 0.355, 1);
}

.my-button:hover {
    transform: translateY(-2px);
    box-shadow: 0 4px 12px rgba(64, 158, 255, 0.2);
}

.my-button:active {
    transform: translateY(0) scale(0.98);
}
```

#### 效果类型：
- **Primary 按钮**：蓝色阴影 `rgba(64, 158, 255, 0.4)`
- **Success 按钮**：绿色阴影 `rgba(103, 194, 58, 0.4)`
- **Warning 按钮**：橙色阴影 `rgba(230, 162, 60, 0.4)`
- **Danger 按钮**：红色阴影 `rgba(245, 108, 108, 0.4)`

---

### 2. Card 卡片 - 悬停动画

#### 添加的效果：
- ✅ **上浮效果**：悬停时卡片上浮 4px
- ✅ **阴影增强**：悬停时阴影从 2px 扩散到 8px
- ✅ **平滑过渡**：0.3s 的柔和过渡

#### 技术细节：
```css
.my-card {
    transition: all 0.3s;
}

.my-card.is-always-shadow:hover {
    transform: translateY(-4px);
    box-shadow: 0 8px 20px 0 rgba(0, 0, 0, 0.15);
}

.my-card.is-hover-shadow:hover {
    box-shadow: 0 8px 20px 0 rgba(0, 0, 0, 0.15);
    transform: translateY(-4px);
}
```

#### 使用建议：
- `shadow="always"` - 始终有阴影，悬停时增强
- `shadow="hover"` - 仅悬停时显示阴影，并伴随上浮

---

### 3. Dialog 对话框 - 进入/离开动画

#### 添加的效果：
- ✅ **遮罩淡入**：背景遮罩淡入淡出
- ✅ **对话框缩放**：对话框从 0.8 倍缩放进入
- ✅ **向上飞入**：进入时从下方 30px 飞入
- ✅ **优雅离开**：离开时轻微缩小到 0.9 倍

#### 技术细节：
```css
/* 遮罩层动画 */
.my-dialog-fade-enter-active,
.my-dialog-fade-leave-active {
    transition: opacity 0.3s cubic-bezier(0.23, 1, 0.32, 1);
}

/* 对话框动画 */
.my-dialog-zoom-enter {
    opacity: 0;
    transform: scale(0.8) translateY(-30px);
}

.my-dialog-zoom-leave-to {
    opacity: 0;
    transform: scale(0.9);
}
```

#### 缓动函数：
- **进入**：`cubic-bezier(0.23, 1, 0.32, 1)` - 弹性缓出
- **离开**：`cubic-bezier(0.755, 0.05, 0.855, 0.06)` - 快速缓入

---

### 4. Input 输入框 - 聚焦动画

#### 添加的效果：
- ✅ **聚焦光晕**：获得焦点时显示蓝色光晕
- ✅ **柔和过渡**：边框颜色和阴影平滑过渡
- ✅ **视觉反馈**：明确的焦点状态提示

#### 技术细节：
```css
.my-input__inner {
    transition: all 0.2s cubic-bezier(0.645, 0.045, 0.355, 1);
}

.my-input__inner:focus {
    border-color: #409eff;
    box-shadow: 0 0 0 2px rgba(64, 158, 255, 0.1);
}
```

#### 效果说明：
- 边框从灰色 `#dcdfe6` 变为蓝色 `#409eff`
- 添加 2px 的蓝色光晕作为视觉焦点
- 支持所有尺寸的 Input 组件

---

### 5. Table 表格 - 行悬停动画

#### 添加的效果：
- ✅ **行高亮**：悬停时行背景色变化
- ✅ **轻微缩放**：悬停时行轻微放大 1%
- ✅ **柔和阴影**：悬停时显示淡淡的阴影
- ✅ **流畅过渡**：0.3s 的平滑动画

#### 技术细节：
```css
.my-table tbody tr {
    transition: all 0.3s cubic-bezier(0.645, 0.045, 0.355, 1);
}

.my-table tbody tr:hover {
    background-color: #f5f7fa;
    transform: scale(1.01);
    box-shadow: 0 2px 8px rgba(0, 0, 0, 0.05);
}
```

#### 兼容性：
- ✅ 支持斑马纹表格
- ✅ 支持边框表格
- ✅ 不影响固定表头功能

---

### 6. Form 表单 - 错误提示动画

#### 添加的效果：
- ✅ **抖动提示**：错误出现时轻微抖动
- ✅ **淡入效果**：错误消息淡入显示
- ✅ **位移动画**：从上方 5px 位置滑入
- ✅ **平滑消失**：错误消除时淡出

#### 技术细节：
```css
/* 进入动画 */
.my-form-error-enter-active {
    animation: my-form-shake 0.3s;
    transition: all 0.3s;
}

/* 抖动关键帧 */
@keyframes my-form-shake {
    0%, 100% {
        transform: translateX(0);
    }
    10%, 30%, 50%, 70%, 90% {
        transform: translateX(-5px);
    }
    20%, 40%, 60%, 80% {
        transform: translateX(5px);
    }
}
```

#### 动画时序：
1. **0.3s** - 抖动动画，吸引用户注意
2. **同时** - 淡入和向下滑动
3. **离开** - 简单的淡出效果

## 🎯 动画设计原则

### 1. 性能优先
- ✅ 使用 `transform` 和 `opacity` 实现动画（GPU 加速）
- ✅ 避免使用 `left`、`top`、`width`、`height` 等触发重排的属性
- ✅ 合理的动画时长（0.2s - 0.3s）

### 2. 用户体验
- ✅ 动画流畅自然，不突兀
- ✅ 提供清晰的交互反馈
- ✅ 不妨碍用户操作

### 3. 一致性
- ✅ 统一的缓动函数：`cubic-bezier(0.645, 0.045, 0.355, 1)`
- ✅ 统一的动画时长：主要使用 0.3s
- ✅ 统一的设计语言：柔和、优雅

## 🎨 使用示例

### 在项目中体验动画效果

打开 `index.html`，你可以立即看到所有动画效果：

```html
<!-- Button 悬停效果 -->
<my-button type="primary">悬停试试</my-button>

<!-- Card 悬停效果 -->
<my-card shadow="hover">
    <p>鼠标悬停查看效果</p>
</my-card>

<!-- Dialog 进入/离开动画 -->
<my-button @click="showDialog = true">打开对话框</my-button>
<my-dialog :visible.sync="showDialog" title="动画演示">
    注意对话框出现和消失的动画
</my-dialog>

<!-- Input 聚焦效果 -->
<my-input v-model="text" placeholder="点击输入框查看效果"></my-input>

<!-- Table 行悬停 -->
<my-table :data="tableData">
    <my-table-column prop="name" label="姓名"></my-table-column>
</my-table>

<!-- Form 错误提示动画 -->
<my-form :model="form" :rules="rules">
    <my-form-item label="用户名" prop="username">
        <my-input v-model="form.username"></my-input>
    </my-form-item>
</my-form>
```
