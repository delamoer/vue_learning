💡 函数式组件优化说明

TableColumn 组件使用了 functional: true 标记为函数式组件：

  • 无状态：没有 data、computed、watch
  • 无实例：没有 this 上下文，无法访问 this.$emit 等
  • 无生命周期：没有 created、mounted 等钩子
  • 性能更优：渲染开销更小，适合大量重复渲染的场景
  • 纯配置：TableColumn 只传递配置信息给 Table
