🔄 动态组件与 keep-alive 详解

Vue 2 组件进阶 - 面试高频 + 性能优化必备

📚 核心概念

动态组件：通过 <component :is="xxx"> 动态切换不同组件
keep-alive：缓存组件实例，避免重复创建销毁，提升性能

🎯 动态组件

一个挂载点，多个组件轮流显示。适用于 Tab 切换、多步骤表单等场景

💾 keep-alive

缓存不活动的组件实例，保留组件状态，避免重复渲染

⚡ 性能优化

减少组件创建/销毁开销，保留用户输入状态，提升用户体验

💾 Demo 2: keep-alive 缓存组件
解决方案：使用 <keep-alive> 包裹动态组件
效果：
1. 组件只会创建一次，切换时不会销毁
2. 输入的状态会被保留
3. 新增生命周期钩子：activated 和 deactivated

🎯 Demo 3: 条件缓存（include/exclude）
实战需求：并非所有组件都需要缓存
解决方案：
1. include：只缓存指定的组件（白名单）
2. exclude：不缓存指定的组件（黑名单）
3. 支持字符串、正则、数组三种写法

🔢 Demo 4: 缓存数量限制（max）
问题：缓存太多组件会占用内存
解决：使用 max 属性限制缓存数量
策略：使用 LRU（Least Recently Used）算法，淘汰最久未使用的实例

示例：最多缓存 2 个组件

🎛️ 缓存限制：max="2"

访问 3 个以上的页面，观察缓存淘汰机制

💡 观察 LRU 策略

步骤：

  1. 依次访问项目1、项目2、项目3（此时项目1被淘汰，查看日志有 destroyed）
  2. 再次访问项目1（会重新创建，输入丢失）
  3. 此时项目2被淘汰（最久未使用）

结论：只有最近访问的 2 个组件被缓存

⚠️ keep-alive 注意事项
  1. name 选项必须设置：include/exclude 匹配的是组件的 name，不是标签名
  2. 新增的生命周期：activated（激活） 和 deactivated（停用）
  3. 不会触发：缓存的组件不会再触发 created/mounted/destroyed
  4. 内存管理：大型应用务必设置 max，避免缓存过多组件
  5. 定时器处理：在 deactivated 中清理定时器，activated 中重新创建
  6. 不能缓存：keep-alive 只能有一个直接子元素（不能用 v-for）
🔄 生命周期对比
场景 普通组件 keep-alive 组件
首次渲染 created → mounted created → mounted → activated
组件切换（离开） beforeDestroy → destroyed deactivated
组件切换（返回） created → mounted（重新创建） activated（从缓存恢复）
组件销毁 beforeDestroy → destroyed deactivated → beforeDestroy → destroyed
✅ keep-alive 应用场景
场景 说明 配置建议
Tab 切换 频繁切换的 Tab 页面 缓存所有，不设置 max
列表 ↔ 详情 从列表进入详情，返回时保留滚动位置 只缓存列表页
多步骤表单 前后翻页不丢失输入 缓存所有步骤
路由缓存 页面级缓存（配合 vue-router） 设置 max="5-10"
高开销组件 图表、编辑器等渲染耗时的组件 按需缓存，设置 include
💡 keep-alive 最佳实践
1️⃣ 明确组件 name

2️⃣ 合理使用生命周期

3️⃣ 设置缓存上限
// ✅ 根据应用规模设置 max // 小型应用（5-10 个页面） <keep-alive :max="5"> // 中型应用（10-30 个页面） <keep-alive :max="10"> // 大型应用（30+ 个页面） <keep-alive :max="15"> // ⚠️ 不设置 max 可能导致内存泄漏
4️⃣ 条件缓存

🎓 面试高频问题
Q1: keep-alive 的原理是什么？

答：

  • keep-alive 是 Vue 的内置抽象组件，不会渲染成 DOM 元素
  • 它会缓存不活动的组件实例，而不是销毁它们
  • 使用 LRU 策略管理缓存，当缓存数量超过 max 时淘汰最久未使用的实例
  • 内部通过 VNode 缓存实现，保存组件的 VNode 和真实 DOM
Q2: activated 和 mounted 有什么区别？

答：

  • mounted：只在组件首次创建时调用一次
  • activated：每次组件被激活（显示）时都会调用
  • 缓存组件首次渲染：created → mounted → activated
  • 缓存组件再次显示：只触发 activated（不触发 mounted）
Q3: keep-alive 如何配合路由使用？
// 1. 在路由配置中设置 meta { path: '/list', component: UserList, meta: { keepAlive: true } // 需要缓存 } // 2. 在 App.vue 中条件渲染 <keep-alive> <router-view v-if="$route.meta.keepAlive"></router-view> </keep-alive> <router-view v-if="!$route.meta.keepAlive"></router-view>
Q4: 缓存组件中的定时器如何处理？
// ✅ 正确做法：在 activated/deactivated 中管理 data() { return { timer: null }; }, activated() { // 激活时启动定时器 this.timer = setInterval(() => { this.fetchData(); }, 5000); }, deactivated() { // 停用时清除定时器 clearInterval(this.timer); this.timer = null; } // ❌ 错误做法：只在 mounted 中创建，不清理 mounted() { setInterval(() => { this.fetchData(); }, 5000); // 组件隐藏后仍在运行！❌ }
