🎯 $refs 引用访问详解

Vue 2 组件进阶 - 掌握组件和DOM的引用访问技巧

📚 什么是 $refs？

$refs 是 Vue 提供的一个特殊属性，用于直接访问 DOM 元素或子组件实例。 它提供了一种"非响应式"的方式来操作 DOM 和组件，是 Vue 中为数不多可以直接访问底层的 API。

🎨 访问 DOM 元素

可以直接获取真实的 DOM 节点，进行原生操作（如 focus、滚动等）

🔧 访问子组件实例

可以直接调用子组件的方法、访问子组件的数据

⚡ 使用场景

表单聚焦、动画控制、第三方库集成、组件通信等

📝 Demo 1: 访问 DOM 元素
核心知识：
1. 使用 ref="xxx" 给元素添加引用标识
2. 通过 this.$refs.xxx 获取 DOM 元素
3. 可以调用原生 DOM 方法（如 focus、select、scroll 等）
实战场景：表单自动聚焦、输入框选中文本、滚动定位

🔧 Demo 2: 访问子组件实例
核心知识：
1. 给组件添加 ref 属性
2. 通过 this.$refs 可以访问子组件的实例

⚠️ 注意：不推荐直接修改子组件数据，建议通过 props 和事件通信

⚠️ 使用 $refs 的注意事项
  1. $refs 不是响应式的：$refs 仅在组件渲染完成后填充，不要在模板或计算属性中使用
  2. 避免过度使用：尽量使用 props 和事件进行组件通信，$refs 应该作为"应急方案"
  3. 在 mounted 之后访问：确保在 mounted 钩子之后访问 $refs，否则可能为 undefined
  4. v-for 中的 refs 是数组：循环中的 ref 会被收集成数组，访问时要注意
  5. 不推荐修改子组件数据：虽然可以直接修改，但会破坏单向数据流
✅ $refs 的最佳使用场景
场景 说明 示例
表单聚焦 自动聚焦到输入框 登录页面自动聚焦到用户名输入框

复杂组件控制 父组件需要精细控制子组件 视频播放器、图表组件的控制
动画触发 手动触发动画 触发 CSS 动画或 JS 动画
💡 $refs 最佳实践
✅ 推荐做法
  • 用于表单验证和焦点控制
  • 用于集成第三方 DOM 库
  • 用于获取 DOM 元素尺寸和位置
  • 用于调用子组件的公开方法
  • 在 mounted 钩子之后使用
❌ 避免做法
  • 不要在计算属性中使用 $refs
  • 不要在模板中使用 $refs
  • 不要代替 props 和事件通信
  • 不要直接修改子组件的数据
  • 避免在 created 中访问 $refs
