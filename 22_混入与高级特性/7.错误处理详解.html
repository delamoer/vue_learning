⚠️ Vue 2 错误处理详解

errorCaptured 组件错误边界 · Vue.config.errorHandler 全局错误捕获 · Vue.config.warnHandler · 生产监控实践

📌 错误处理三道防线

防线API作用范围典型用途
第一道 try/catch in 方法 精确到某个方法调用 处理特定的异步/同步错误
第二道 errorCaptured 钩子 组件及其所有子孙组件 错误边界组件、局部降级 UI
第三道 Vue.config.errorHandler 全局所有 Vue 组件 上报到 Sentry / 日志监控平台
传播规则：错误先向上冒泡到最近的 errorCaptured 钩子； 若该钩子返回 false 则停止传播；否则继续向上直到 Vue.config.errorHandler。

Demo 1：errorCaptured — 组件级错误边界

签名：errorCaptured(err: Error, vm: Component, info: string): boolean | void
• 在父/祖先组件上定义，捕获子孙组件抛出的错误（含 render、生命周期、事件处理器）。
• 返回 false → 阻止错误继续向上传播（不进入 errorHandler）。
• 不返回 / 返回 true → 错误继续向上冒泡。 
// ① 错误边界组件（展示降级 UI）
const ErrorBoundary = {
  data() {
    return { hasError: false, errorMsg: '', errorInfo: '' }
  },
  errorCaptured(err, vm, info) {
    this.hasError  = true
    this.errorMsg  = err.message
    this.errorInfo = info
    // 返回 false：错误到此为止，不再传给 Vue.config.errorHandler
    return false
  },
  methods: {
    retry() { this.hasError = false }
  },
  template: `
    <div>
      <div v-if="hasError" class="error-ui">
        <p>⚠️ 子组件出现错误</p>
        <p>{{ errorMsg }}</p>
        <small>位置：{{ errorInfo }}</small>
        <br>
        <button @click="retry">重试</button>
      </div>
      <slot v-else />
    </div>
  `
}

// ② 可能出错的子组件
const BuggyChild = {
  data() { return { throwOnMount: false, throwOnRender: false } },
  mounted() {
    if (this.throwOnMount) throw new Error('mounted 钩子中的错误')
  },
  template: `
    <div>
      <span v-if="throwOnRender">{{ undefined.property }}</span>
      <span v-else>子组件正常运行中 ✅</span>
    </div>
  `
}

Demo 2：Vue.config.errorHandler — 全局错误捕获

注意：在 Vue 实例创建之前（new Vue(...) 之前）设置，否则部分初始化错误无法被捕获。 生产项目应在 main.js 最顶部配置。 
// main.js 顶部（new Vue 之前）

// 1. 全局错误处理器
Vue.config.errorHandler = function(err, vm, info) {
  // err   : Error 对象，包含 stack
  // vm    : 发生错误的组件实例
  // info  : Vue 提供的错误说明字符串（如 "render function", "mounted hook"）

  console.error('[全局错误]', err)
  console.error('[组件名]', vm?.$options?.name)
  console.error('[位置]', info)

  // 上报到 Sentry（生产示例）
  // Sentry.captureException(err, { extra: { info, component: vm?.$options?.name } })
}

// 2. 全局警告处理器（开发阶段调试用）
Vue.config.warnHandler = function(msg, vm, trace) {
  // 过滤掉不关心的 warn，只保留重要的
  if (msg.includes('Missing required prop')) {
    console.warn('[PropWarning]', msg, trace)
  }
  // warnHandler 只在 development 模式下生效，生产会被忽略
}
与 errorCaptured 的分工：
• errorCaptured 返回 false → 错误被局部吞掉，不进入 errorHandler（适合"局部降级 UI"）
• errorCaptured 不返回 / 返回其他值 → 错误继续上报到 errorHandler（适合"记录 + 降级并存"）

Demo 4：异步错误的陷阱与正确处理

⚠️ 重要陷阱：errorCaptured 和 Vue.config.errorHandler 无法自动捕获以下场景的错误：
  • 原生 setTimeout / setInterval 回调中的错误
  • 普通 Promise 中未 catch 的 rejection
  • 独立的 async 函数（未被 Vue 感知的异步流）
// ❌ Vue 无法捕获
mounted() {
  setTimeout(() => {
    throw new Error('这个错误 errorCaptured / errorHandler 都抓不到')
  }, 1000)
}

// ✅ 方案 1：手动 try/catch
mounted() {
  setTimeout(() => {
    try {
      riskyOperation()
    } catch(err) {
      this.handleError(err)   // 自行上报或更新 UI
    }
  }, 1000)
}

// ✅ 方案 2：async/await（Vue 生命周期钩子 / 方法中的 async 会被捕获）
async mounted() {
  // Vue 会包装生命周期钩子，所以这里的错误能被 errorCaptured 捕获
  const data = await fetchData()   // 若 fetchData reject → Vue 捕获 ✅
}

// ✅ 方案 3：全局兜底 unhandledrejection
window.addEventListener('unhandledrejection', (event) => {
  console.error('未处理的 Promise 异常:', event.reason)
  // Sentry.captureException(event.reason)
  event.preventDefault()  // 阻止默认的 console error
})

📊 总结：错误处理完整方案

// main.js 生产级模板

// ① 全局 Vue 错误 → 上报监控
Vue.config.errorHandler = (err, vm, info) => {
  reportToMonitor({ err, component: vm?.$options?.name, info })
}

// ② 未捕获的 Promise rejection → 上报监控
window.addEventListener('unhandledrejection', e => {
  reportToMonitor({ err: e.reason, type: 'promise' })
})

// ③ 关键页面/功能区域 → ErrorBoundary 组件（局部降级 UI）
// <error-boundary>
//   <payment-module />   ← 支付模块崩了不影响其他区域
// </error-boundary>

// ④ 高风险异步操作 → try/catch 精确处理
try {
  await submitOrder(data)
} catch (err) {
  this.errorMsg = '提交失败，请重试'
}
方式能捕获不能捕获
errorCapturedrender错误、生命周期、methods、async钩子setTimeout、自由Promise
errorHandler同上（全局范围）同上
unhandledrejection未 catch 的 Promise rejection同步错误
try/catch任意位置的同步和 await 异步-（最全面）
💡 记忆口诀：Vue 错误 → errorCaptured（局部）→ errorHandler（全局）→ unhandledrejection（Promise 兜底）→ try/catch（精确处理）
