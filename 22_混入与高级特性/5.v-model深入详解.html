🔗 v-model 深入详解

双向数据绑定原理 - 理解 Vue 表单的核心

💡 什么是 v-model？

v-model是 Vue 提供的双向数据绑定指令，常用于表单元素，实现数据与UI的自动同步。

🎯 v-model 的本质

v-model 本质上是一个语法糖，它在内部为不同的元素使用不同的属性和事件：

  • ✅ <input type="text">：绑定 value + 监听 input 事件
  • ✅ <input type="checkbox">：绑定 checked + 监听 change 事件
  • ✅ <input type="radio">：绑定 checked + 监听 change 事件
  • ✅ <select>：绑定 value + 监听 change 事件
  • ✅ <textarea>：绑定 value + 监听 input 事件

📦 v-model 的原理

// v-model 的语法糖（文本输入框）
<input v-model="message">

// 等价于
<input 
    :value="message"
    @input="message = $event.target.value"
>

🆚 v-model vs .sync - 理解两者关系

💡 你说："v-model 是特定的 sync" 准确吗？
⚠️ 更准确的说法：

v-model 和 .sync 是"兄弟"，不是父子关系！
它们都是 props + emit 的语法糖，只是约定不同：
• v-model = 表单专用的固定版（value + input）
• .sync = 通用版（任意 prop + update:xxx）

📊 完整对比表格：

对比维度 v-model .sync props + emit
本质 语法糖 ✅ 语法糖 ✅ 原始方式 ⚙️
prop 名 value（固定） 任意名字 任意名字
事件名 input（固定） update:xxx（固定格式） 任意名字
数量限制 每个组件只能 1 个 可以有多个 无限制
主要用途 📝 表单输入 🪟 组件状态 所有场景
出现时间 Vue 1.x（很早） Vue 2.3+（回归） 从一开始就有
使用频率 ⭐⭐⭐⭐⭐ 极高 ⭐⭐⭐⭐⭐ 极高 ⭐⭐⭐ 中等

🔍 三者关系图：


props + emit（爷爷 - 最原始的方式）
    │
    ├── v-model（大儿子 - 专门为表单设计）
    │   ├── prop 名：必须是 value
    │   ├── 事件名：必须是 input
    │   ├── 数量：每个组件只能一个
    │   └── 用途：Input、Select、Textarea 等表单组件
    │
    └── .sync（二儿子 - 通用的组件状态同步）
        ├── prop 名：任意（如 visible、collapsed）
        ├── 事件名：update:xxx（如 update:visible）
        ├── 数量：可以有多个
        └── 用途：Dialog、Drawer、Sidebar 等 UI 组件

// ==================== 代码对比 ====================

// 1. v-model（表单专用）
<custom-input v-model="username"></custom-input>
// 等价于 ↓
<custom-input 
    :value="username"           ← prop 必须叫 value
    @input="username=$event"    ← 事件必须叫 input
></custom-input>

// 2. .sync（通用双向绑定）
<dialog :visible.sync="show"></dialog>
// 等价于 ↓
<dialog 
    :visible="show"                    ← prop 名任意
    @update:visible="show=$event"      ← 事件是 update:xxx
></dialog>

// 3. props + emit（原始方式）
<my-component 
    :count="num"
    @increment="num=$event"
></my-component>
✅ 正确的理解：

1. v-model 和 .sync 是平级关系
它们都是 props + emit 的封装，只是约定不同

2. 可以这样类比：
• v-model = 专门为表单输入设计的"固定版双向绑定"
• .sync = 为组件状态设计的"灵活版双向绑定"

3. 使用建议：
• 📝 Input、Select、Textarea → 用 v-model
• 🪟 Dialog、Drawer、Sidebar → 用 .sync
• 📊 需要多个属性双向绑定 → 用 .sync（v-model 只能一个）
• 🎯 复杂的业务逻辑 → 直接用 props + emit

💡 记忆口诀：

爷爷有两个儿子：
• 大儿子 v-model：专注表单，固定套路（value + input）
• 二儿子 .sync：通用全能，灵活应变（任意 prop + update:xxx）
• 爷爷 props + emit：最原始，什么都能干但很啰嗦

它们本质上都是一家人，都是双向绑定！

📘 Demo 2: v-model 的修饰符

🎯 .lazy、.number、.trim
💡 三个修饰符：
  • .lazy：在 change 事件后更新（而不是 input）
  • .number：自动将用户输入转为数值类型
  • .trim：自动去除首尾空格
// .lazy - 失去焦点后才更新 <input v-model.lazy="msg"> // .number - 自动转为数字 <input v-model.number="age" type="number"> // .trim - 去除首尾空格 <input v-model.trim="name"> // 可以组合使用 <input v-model.lazy.trim="email">

📘 Demo 3: 在组件上使用 v-model

🎯 自定义组件实现 v-model
💡 组件 v-model 原理： 
<custom-input v-model="searchText"></custom-input>

// 等价于
<custom-input
    :value="searchText"
    @input="searchText = $event"
></custom-input>
搜索关键词：{{ searchText }}
// 自定义输入组件 Vue.component('custom-input', { props: { value: { type: String, default: '' } }, template: ` <input :value="value" @input="$emit('input', $event.target.value)" class="custom-input" /> ` }); // 使用 <custom-input v-model="searchText"></custom-input>
⚠️ 关键要点：
  • 组件必须接收名为 value 的 prop
  • 组件必须触发名为 input 的事件
  • 事件参数就是新的值

📘 Demo 4: 自定义 v-model 的 prop 和 event

🎯 使用 model 选项自定义
💡 为什么需要自定义？
某些组件可能想用 value 属性做其他用途（如 checkbox 的原生值），这时可以通过 model 选项自定义 v-model 的行为。
同意协议：{{ agreed ? '已同意' : '未同意' }}

// 自定义复选框组件 Vue.component('custom-checkbox', { // 自定义 v-model 的 prop 和 event model: { prop: 'checked', // 使用 checked 而不是 value event: 'change' // 使用 change 而不是 input }, props: { checked: { type: Boolean, default: false } }, template: ` <label style="cursor: pointer; display: flex; align-items: center; gap: 8px;"> <input type="checkbox" :checked="checked" @change="$emit('change', $event.target.checked)" style="width: 18px; height: 18px;" /> <slot></slot> </label> ` }); // 使用（v-model 会自动使用 checked prop 和 change 事件） <custom-checkbox v-model="agreed"> 我已阅读并同意《用户协议》 </custom-checkbox>

📚 知识点总结

✅ v-model 核心要点

  • 本质：是 :value + @input 的语法糖
  • 原生表单：支持 input、textarea、select、checkbox、radio
  • 修饰符：.lazy、.number、.trim
  • 组件使用：需要 value prop 和 input 事件
  • 自定义：通过 model 选项改变默认行为

💡 v-model vs .sync

特性 v-model .sync
数量限制 一个组件只能有一个 可以有多个
默认 prop value（可自定义） 任意 prop 名
适用场景 表单输入控件 组件状态同步

⚠️ 注意事项

  • v-model 会忽略表单元素的 value、checked、selected 初始值
  • 应该在 data 中声明初始值
  • 在 textarea 中，不要使用插值：<textarea>{{text}}</textarea> ❌
  • 应该使用 v-model：<textarea v-model="text"></textarea> ✅
