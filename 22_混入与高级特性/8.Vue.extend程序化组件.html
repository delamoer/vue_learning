🔌 Vue.extend — 程序化组件

命令式调用组件（$toast / $loading）· 挂载到 body · 组件构造函数 · Vue.prototype 扩展

📌 什么是 Vue.extend？

Vue.extend(options) 基于一个普通组件对象创建一个子类构造函数， 然后可以用 new 手动实例化、挂载到 DOM 上——不需要在模板里写 <my-component />， 而是像调用函数一样 this.$toast('操作成功')。

Element UI / Vant 的底层原理：
this.$message.success('保存成功')、this.$loading()、this.$notify() 等命令式 API 全部基于 Vue.extend 实现。理解它，你也能手写自己的组件库工具方法。 
// 三步走：extend → new 实例化 → $mount 挂载

// 1. 创建构造函数
const ToastConstructor = Vue.extend(ToastComponent)

// 2. 实例化（可以传 propsData）
const instance = new ToastConstructor({
  propsData: { message: '操作成功', type: 'success' }
})

// 3. 挂载（不传参 = 创建一个脱离文档的DOM节点）
instance.$mount()
document.body.appendChild(instance.$el)

// 4. 若干秒后销毁
setTimeout(() => {
  document.body.removeChild(instance.$el)
  instance.$destroy()
}, 2500)

Demo 1：手写 $toast 消息提示

完全可运行 — 点击下方按钮查看效果
// toast.js — 实现文件

// ① Toast 组件定义
const ToastComp = {
  data() { return { message: '', type: 'info', visible: true } },
  template: `
    <transition name="fade">
      <div v-if="visible" :class="['v-toast', 'v-toast-' + type]">
        {{ message }}
      </div>
    </transition>
  `
}

// ② 构造函数（只创建一次）
const ToastConstructor = Vue.extend(ToastComp)

// ③ 工厂函数
function toast(message, type = 'info', duration = 2500) {
  const instance = new ToastConstructor()
  instance.message = message
  instance.type    = type
  instance.$mount()
  document.body.appendChild(instance.$el)
  setTimeout(() => {
    instance.visible = false
    setTimeout(() => { instance.$destroy(); instance.$el.remove() }, 300)
  }, duration)
}

// ④ 注册到 Vue.prototype → 所有组件可 this.$toast 调用
Vue.prototype.$toast = toast

Demo 2：手写全屏 $loading

Loading 需要单例模式——避免重复创建多个遮罩层
// loading.js — 单例模式

const LoadingComp = {
  data() { return { text: '加载中...', visible: false } },
  template: `
    <transition name="fade">
      <div v-if="visible" class="v-loading-mask">
        <div class="v-loading-box">
          <div class="v-loading-spinner"></div>
          <div>{{ text }}</div>
        </div>
      </div>
    </transition>
  `
}

// 单例：整个应用只创建一个 Loading 实例
let instance = null

function getOrCreateInstance() {
  if (!instance) {
    instance = new (Vue.extend(LoadingComp))()
    instance.$mount()
    document.body.appendChild(instance.$el)
  }
  return instance
}

const Loading = {
  show(text = '加载中...') {
    const inst = getOrCreateInstance()
    inst.text    = text
    inst.visible = true
  },
  hide() {
    if (instance) instance.visible = false
  }
}

Vue.prototype.$loading = Loading

📊 关键对比：声明式 vs 程序化

方式使用方式适用场景典型例子
声明式 <my-modal v-if="show" /> 固定位置、与父组件强绑定 表单弹窗、侧边栏
程序化
(Vue.extend)		 this.$toast('...') 全局弹出、与当前组件无关 消息提示、全屏Loading、确认弹框
⚠️ 注意事项：
1. 程序化组件不在 Vue 组件树中，无法通过 Vuex / provide-inject 自动获取数据，需手动传入 store。
2. 若需要访问 store：new Ctor({ parent: vm }) 传入父实例，或 new Ctor({ store }) 手动注入。
3. 务必在适当时机调用 instance.$destroy() + instance.$el.remove()，防止内存泄漏。 
// 需要访问 Vuex store 的程序化组件（进阶）
import store from '@/store'

function createConfirm(options) {
  const instance = new (Vue.extend(ConfirmComp))({
    store,             // ✅ 手动注入 store
    propsData: options
  })
  instance.$mount()
  document.body.appendChild(instance.$el)
  return instance
}
