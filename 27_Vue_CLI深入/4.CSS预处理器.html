🎨 27-4 CSS 预处理器（Sass/Less）

1. 安装与配置

Vue CLI 通过 Webpack loader 支持 CSS 预处理器，需要手动安装对应的依赖。

# 安装 Sass (推荐，生态更好)
npm install -D sass sass-loader

# 安装 Less
npm install -D less less-loader

# 安装 Stylus
npm install -D stylus stylus-loader
Vue CLI 5 注意： 使用 sass（非 node-sass），sass-loader 推荐 v12+。 项目中已有 @vue/cli-service，只需安装 sass 和 sass-loader 即可， 无需在 vue.config.js 额外配置 loader。

在 .vue 组件中使用

<!-- 只需在 style 标签加 lang 属性 -->
<style lang="scss" scoped>
.user-card {
  $primary: #42b983;     // 局部变量

  padding: 16px;
  border: 2px solid $primary;

  &:hover {              // 嵌套 & 父选择器
    background: lighten($primary, 40%);
  }

  .title {               // 嵌套选择器（避免 BEM 写法的冗长）
    font-size: 1.2rem;
    font-weight: bold;
  }
}
</style>

<style lang="less" scoped>
.user-card {
  @primary: #42b983;     // Less 变量用 @

  padding: 16px;
  .title { font-weight: bold; }
}
</style>

2. 全局变量自动注入（关键配置）

最大的痛点：在每个组件里都要 @import 变量文件。通过 vue.config.js 配置自动注入，一劳永逸。

// src/styles/variables.scss — 全局变量文件
$primary-color: #42b983;
$danger-color:  #f56c6c;
$warning-color: #e6a23c;
$text-base:     #303133;
$text-muted:    #909399;
$border-color:  #dcdfe6;
$border-radius: 4px;

$font-size-sm: 12px;
$font-size-md: 14px;
$font-size-lg: 16px;

$spacing-xs: 4px;
$spacing-sm: 8px;
$spacing-md: 16px;
$spacing-lg: 24px;
// vue.config.js — 自动注入到每个组件的 style 块
const { defineConfig } = require('@vue/cli-service')

module.exports = defineConfig({
  css: {
    loaderOptions: {
      sass: {
        // sass-loader v8+: prependData → additionalData
        additionalData: `@import "@/styles/variables.scss";`
      },
      // Less 的写法
      less: {
        additionalData: `@import "@/styles/variables.less";`
      }
    }
  }
})

配置后，每个 <style lang="scss"> 块都自动拥有变量，无需手动 import：

<!-- 组件中直接使用全局变量，无需 @import -->
<style lang="scss" scoped>
.btn {
  background: $primary-color;   // ✅ 直接用，不需要 @import
  border-radius: $border-radius;
  padding: $spacing-sm $spacing-md;
  font-size: $font-size-md;
}
</style>

3. 样式 Mixin 复用

// src/styles/mixins.scss

// 单行文字超出省略
@mixin ellipsis {
  overflow: hidden;
  text-overflow: ellipsis;
  white-space: nowrap;
}

// 多行文字超出省略
@mixin line-clamp($lines) {
  display: -webkit-box;
  -webkit-box-orient: vertical;
  -webkit-line-clamp: $lines;
  overflow: hidden;
}

// flex 居中
@mixin flex-center {
  display: flex;
  align-items: center;
  justify-content: center;
}

// 响应式断点
@mixin mobile {
  @media (max-width: 768px) { @content; }
}
@mixin tablet {
  @media (min-width: 769px) and (max-width: 1024px) { @content; }
}

// ---- 使用方式 ----
.card-title {
  @include ellipsis;             // 单行超出省略
}
.description {
  @include line-clamp(3);        // 三行超出省略
}
.loading-mask {
  @include flex-center;          // flex 居中遮罩
  position: absolute;
}
.sidebar {
  width: 240px;
  @include mobile {              // 手机上隐藏侧边栏
    display: none;
  }
}

4. 全局样式组织结构

// src/styles/index.scss — 入口（在 main.js 中 import）
@import "./reset";           // CSS 重置
@import "./variables";      // 变量（不包含任何 CSS，无副作用）
@import "./mixins";         // Mixin（不包含任何 CSS，无副作用）
@import "./base";            // 基础全局样式（body、h1-h6、a、ul…）
@import "./transition";     // 全局 transition 动画类
@import "./utilities";      // 工具类（.text-center / .mt-16…）
// src/styles/reset.scss — 基础重置
*, *::before, *::after { box-sizing: border-box; }
body {
  margin: 0;
  font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif;
  font-size: $font-size-md;    // 引用变量（因为全局注入，这里可以直接用）
  color: $text-base;
  line-height: 1.5;
  -webkit-font-smoothing: antialiased;
}
a { color: $primary-color; text-decoration: none; }
img { max-width: 100%; }
ul, ol { list-style: none; padding: 0; margin: 0; }

5. Sass vs Less 选择指南

Sass (SCSS)Less
语法类 CSS（.scss）或缩进式（.sass）类 CSS，与原生 CSS 差异最小
变量声明$primary: #42b983;@primary: #42b983;
嵌套支持支持
Mixin@mixin / @include.mixin()
函数内置函数丰富（颜色、数学）较少
生态Bootstrap 5, 更广泛Ant Design（历史），Element Plus 已迁至 Sass
推荐度⭐⭐⭐⭐⭐ 首选⭐⭐⭐ 老项目延续用
建议： 新项目统一使用 Sass（SCSS 语法），与主流 UI 库（Element Plus、Vuetify）保持一致。

6. 深度选择器完整总结

场景写法
普通 CSS + scoped.parent >>> .child {}
Sass/Less + scoped.parent ::v-deep .child {}
Vue 3 所有情况.parent :deep(.child) {}
穿透到插槽内容::v-slotted(.child) {}（Vue 3）
全局样式（不受 scoped 限制）::v-global(.g-class) {}（Vue 3）
<!-- 实际使用示例：修改 Element UI 的 el-dialog 样式 -->
<style lang="scss" scoped>
.my-dialog {
  ::v-deep .el-dialog__header {
    background: $primary-color;
    padding: 16px 20px;
  }

  ::v-deep .el-dialog__title {
    color: #fff;
    font-weight: bold;
  }

  ::v-deep .el-dialog__body {
    padding: $spacing-lg;
  }
}
</style>
