1. SFC 三块结构深入

.vue 文件由三个块组成，每个块都有丰富的扩展选项。

<!-- 完整的 SFC 结构及可选属性 -->

<!-- ① template：只能有一个根元素（Vue 2 限制） -->
<template>
  <div class="user-card">...</div>
</template>

<!-- ② script：组件选项 -->
<script>
export default {
  name: 'UserCard',    // ⭐ 强烈推荐加 name，便于 Devtools 调试和 keep-alive
  props: {},
  data() { return {} },
  computed: {},
  methods: {},
  watch: {},
  created() {},
  mounted() {}
}
</script>

<!-- ③ style：支持多个，可混用 scoped 和非 scoped -->
<style scoped>   /* scoped：样式隔离 */
</style>
<style>          /* 无 scoped：全局生效 */
</style>

2. Scoped CSS 原理与穿透

Scoped 的实现原理

Vue 通过给组件的每个 DOM 元素添加唯一的 data-v-xxxxxx 属性，然后给 CSS 选择器添加属性选择器来实现作用域隔离。

/* 源码写法（.vue 文件中） */
.btn { color: red; }

/* 编译后（Webpack 处理结果） */
.btn[data-v-7ba5bd90] { color: red; }

/* DOM 中的元素 */
<button data-v-7ba5bd90 class="btn">点击</button>

深度作用选择器（穿透子组件）

当你想在父组件修改子组件/第三方组件的样式时，需要用"深度选择器"绕过 scoped。

/* 场景：修改 Element UI 组件的内部样式 */

/* Vue 2 + 普通 CSS */
.parent >>> .el-input__inner { border-color: red; }

/* Vue 2 + Sass/Less（推荐） */
.parent ::v-deep .el-input__inner { border-color: red; }

/* 编译后变为（不加 data-v-xxx 限制） */
[data-v-7ba5bd90] .el-input__inner { border-color: red; }
注意： ::v-deep 是 Vue 2.x 的写法。Vue 3 中改为 :deep()。 使用时注意版本。

3. CSS Modules（模块化 CSS）

比 scoped 更彻底的隔离方案：类名会被编译成哈希字符串，在 JS 中作为对象使用。

<!-- 使用 CSS Modules：给 style 加 module 属性 -->
<template>
  <!-- 通过 $style.类名 引用 -->
  <div :class="$style.card">
    <p :class="[$style.text, $style.bold]">内容</p>

    <!-- 动态 class 与 CSS Modules 混用 -->
    <span :class="{ [$style.active]: isActive }">状态</span>
  </div>
</template>

<script>
export default {
  data() {
    return { isActive: true }
  },
  mounted() {
    // 在 JS 中也可以访问编译后的类名
    console.log(this.$style.card)  // "_card_1a2b3c_1"（哈希类名）
  }
}
</script>

<style module>    /* 注意：不加 scoped，加 module */
.card { padding: 16px; border: 1px solid #ccc; }
.text { font-size: 14px; }
.bold { font-weight: bold; }
.active { color: green; }
</style>
scopedCSS Modules
隔离方式属性选择器哈希类名
引用方式普通 class 字符串$style.xxx 对象
动态类名普通更灵活（可在 JS 中处理）
适用场景普通组件样式隔离需要复杂动态样式的场景

4. Functional（函数式）组件

没有响应式数据、没有实例、没有生命周期的组件，渲染性能比普通组件高。

适用场景

✅ 纯展示组件（只接收 props，渲染 UI）

✅ 高频渲染的列表项组件（table-row、list-item）

✅ 包装/高阶组件（包一层但不需要状态）

<!-- 方式1：template 中声明 functional -->
<template functional>
  <!-- functional 组件中没有 this，用 props 和 parent 代替 -->
  <div class="tag-item" :class="{ active: props.active }">
    {{ props.label }}
  </div>
</template>

<script>
export default {
  name: 'TagItem',
  functional: true,   // ⭐ 也可以在这里声明
  props: {
    label: String,
    active: Boolean
  }
  // 没有 data、created、mounted 等
}
</script>

<!-- 方式2：纯 render 函数写法（高阶组件常用）-->
<script>
export default {
  functional: true,
  props: ['level', 'text'],
  render(h, ctx) {             // ctx = { props, data, slots, parent, listeners }
    return h(
      `h${ctx.props.level}`,  // 动态标签 h1~h6
      ctx.data,
      [ctx.props.text]
    )
  }
}
</script>

5. 性能相关：v-once 与 v-memo

<!-- v-once：只渲染一次，之后跳过 diff（静态内容优化）-->
<header v-once>
  <h1>{{ title }}</h1>    <!-- title 改变后不会重新渲染 -->
</header>

<!-- 适合：帮助信息、法律条款等完全静态的大块内容 -->
<div v-once class="terms">
  <!-- 很多段落... -->
</div>
Vue 2 没有 v-memo（v-memo 是 Vue 3.2+ 的功能）。 Vue 2 中的静态内容优化主要通过：v-once（一次性渲染）和 functional 组件。

6. 异步组件（性能优化核心）

将组件代码分割成独立的 chunk，只在需要时才加载，减少首屏体积。

// ① 路由级懒加载（最常用）
const routes = [
  {
    path: '/dashboard',
    // import() 返回 Promise，Webpack 自动拆包
    component: () => import('@/views/Dashboard.vue')
  },
  {
    path: '/chart',
    // 魔法注释：指定 chunk 名，相关页面打进同一个包
    component: () => import(
      /* webpackChunkName: "analytics" */
      '@/views/Chart.vue'
    )
  }
]

// ② 组件级懒加载（弹窗、Tab 内容等）
export default {
  components: {
    // 简单写法
    HeavyChart: () => import('./HeavyChart.vue'),

    // 带加载/失败状态的完整写法
    DataTable: () => ({
      component: import('./DataTable.vue'),
      loading: LoadingSpinner,   // 加载中显示
      error: ErrorComponent,      // 加载失败显示
      delay: 200,                  // 200ms 后才显示 loading
      timeout: 3000               // 3s 超时
    })
  }
}

7. 全局注册 vs 局部注册

全局注册

// main.js
Vue.component('BaseButton', {
  /* ... */
})

✅ 无需每个组件都 import

❌ 无法 Tree-shaking（即使不用也打包）

适合： 全局高频基础组件

局部注册（推荐）

import BaseButton from '@/components/BaseButton'
export default {
  components: { BaseButton }
}

✅ 支持 Tree-shaking

✅ 依赖关系明确

适合： 大多数业务组件

自动全局注册基础组件（进阶技巧）

// src/components/base/index.js — 批量自动注册 Base 开头的组件
import Vue from 'vue'

// require.context 是 Webpack 的功能，扫描目录
const requireComponent = require.context(
  '.',           // 目录：当前目录
  false,         // 不递归子目录
  /Base[A-Z]\w+\.(vue|js)$/  // 匹配 Base 开头的文件
)

requireComponent.keys().forEach(fileName => {
  const componentConfig = requireComponent(fileName)
  const componentName = fileName
    .replace(/^\.\//, '')
    .replace(/\.\w+$/, '')

  Vue.component(
    componentName,
    componentConfig.default || componentConfig
  )
})

// main.js 中引入
import '@/components/base'

场景name 的作用
Vue Devtools在组件树中显示名字，便于定位调试
keep-alive<keep-alive include="UserCard"> 按 name 匹配缓存
递归组件组件在模板中引用自身时通过 name 找到自己
