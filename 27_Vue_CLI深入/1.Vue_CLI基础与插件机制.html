📦 27-1 Vue CLI 基础与插件机制

1. Vue CLI 是什么

Vue CLI 是 Vue.js 官方的命令行工具（Command Line Interface），提供了一套完整的前端开发工程化解决方案。

核心能力

脚手架 快速初始化项目（交互式选择特性）

Dev Server 热重载开发服务器 + 代理

构建 基于 Webpack 的生产构建（压缩、拆包、CDN）

插件系统 可扩展，通过 add 命令添加功能

预设 Preset 可保存配置复用到多个项目

图形界面 vue ui 可视化管理

Vue CLI vs Vite： Vue CLI 基于 Webpack，启动慢但生态成熟；Vite 基于原生 ES Module，启动极快。 Vue 2 项目推荐使用 Vue CLI 5；Vue 3 新项目推荐 Vite。

2. 安装与常用命令

# 全局安装 Vue CLI（需要 Node.js ≥ 12）
npm install -g @vue/cli

# 查看版本
vue --version          # @vue/cli 5.x.x
vue -V

# 创建新项目（交互式）
vue create my-app

# 创建项目（使用默认 Vue 2 配置，跳过交互）
vue create my-app --default

# 图形化界面（浏览器打开）
vue ui

# 在已有项目中添加插件
vue add router
vue add vuex
vue add eslint

3. 项目脚本（package.json scripts）

{
  "scripts": {
    "serve": "vue-cli-service serve",      // 启动开发服务器
    "build": "vue-cli-service build",      // 生产构建
    "lint":  "vue-cli-service lint"         // 代码检查
  }
}
命令作用常用参数
npm run serve启动热重载开发服务器--port 8081, --open, --https
npm run build打包到 dist/ 目录--modern, --report, --target lib
npm run lint检查并自动修复代码--fix
npx vue-cli-service inspect查看完整 Webpack 配置--mode development

4. vue.config.js 完整解析

Vue CLI 项目根目录下的 vue.config.js 是项目的核心配置文件（可选，默认自动生效）。

// vue.config.js
const { defineConfig } = require('@vue/cli-service')

module.exports = defineConfig({
  // ① 应用基础路径（部署到子目录时修改）
  publicPath: process.env.NODE_ENV === 'production'
    ? '/'          // 生产：根目录
    : '/',         // 开发：根目录

  // ② 打包输出目录（默认 dist）
  outputDir: 'dist',

  // ③ 静态资源目录（相对于 outputDir）
  assetsDir: 'static',

  // ④ 生产环境关闭 source map（减小包体积）
  productionSourceMap: false,

  // ⑤ 开发服务器配置
  devServer: {
    port: 8081,          // 端口号
    open: false,         // 启动后自动打开浏览器
    https: false,        // 是否启用 HTTPS
    proxy: {             // API 代理（解决跨域）
      '/api': {
        target: 'http://localhost:3000',
        changeOrigin: true,
        pathRewrite: { '^/api': '' }
      }
    }
  },

  // ⑥ 自定义 Webpack 配置（链式 API）
  chainWebpack(config) {
    // 设置 HTML 标题
    config.plugin('html').tap(args => {
      args[0].title = '我的应用'
      return args
    })
  },

  // ⑦ 覆盖 Webpack 配置（对象合并或函数修改）
  configureWebpack: {
    // 例：添加路径别名
    resolve: {
      alias: {
        '@utils': '@/utils'  // 补充别名（@ 已默认指向 src）
      }
    }
  },

  // ⑧ CSS 相关配置
  css: {
    loaderOptions: {
      sass: {
        // 每个组件自动注入全局变量（Sass）
        additionalData: `@import "@/styles/variables.scss";`
      }
    }
  }
})

5. 插件（Plugin）机制

Vue CLI 的插件系统是其最强大的特性之一，允许在项目中插拔式地添加功能。

插件的两种形式

@vue/cli-plugin-*

官方维护的核心插件

babel、eslint、router、vuex、unit-jest

vue-cli-plugin-*

社区插件

element-ui、vant、axios、mock

插件安装与工作原理

# 添加插件（自动修改代码和 package.json）
vue add element           → vue-cli-plugin-element
vue add @vue/unit-jest    → @vue/cli-plugin-unit-jest

## 插件做了什么？以 router 为例：
# 1. 安装 vue-router 依赖
# 2. 创建 src/router/index.js
# 3. 修改 src/main.js（注入 router）
# 4. 创建示例页面 src/views/

每个插件包含的文件结构

vue-cli-plugin-xxx/ ├── index.js ← Service 插件（修改 Webpack 配置） ├── generator.js ← Generator（生成模板文件、修改 package.json） ├── prompts.js ← 交互式提问（询问用户配置项） └── template/ ← 要注入到项目的文件模板

6. Preset 预设：保存并复用配置

Preset 允许你把一套经过验证的项目配置保存下来，下次创建项目时直接套用。

本地 Preset（~/.vuerc）

// ~/.vuerc（Vue CLI 全局配置文件）
{
  "useTaobaoRegistry": false,
  "presets": {
    "my-vue2-preset": {         ← 你的预设名字
      "useConfigFiles": true,    ← 独立配置文件
      "plugins": {
        "@vue/cli-plugin-babel": {},
        "@vue/cli-plugin-eslint": {
          "config": "standard",
          "lintOn": ["save"]
        },
        "@vue/cli-plugin-router": { "historyMode": true },
        "@vue/cli-plugin-vuex": {}
      },
      "vueVersion": "2"
    }
  }
}

远程 Preset（GitHub 仓库）

# 使用 GitHub 上的 preset
vue create --preset username/my-preset my-app

7. 路径别名 @ 的本质

Vue CLI 默认将 @ 配置为 src 目录的别名，这是 Webpack 的 resolve.alias 功能。

// 在组件中使用 @ 别名（避免 ../../ 层级混乱）
import api from '@/api/user'        // ✅ 推荐
import api from '../../api/user'    // ❌ 不推荐

// 在 CSS 中引用图片也可以用 @
/* background: url(@/assets/logo.png) */
/* @import "@/styles/variables.scss" */

// 扩展更多别名（vue.config.js）
configureWebpack: {
  resolve: {
    alias: {
      '@': path.resolve(__dirname, 'src'),      // 默认已有
      '@components': path.resolve(__dirname, 'src/components'),
      '@views': path.resolve(__dirname, 'src/views'),
      '@api': path.resolve(__dirname, 'src/api')
    }
  }
}
VSCode 别名跳转配置： 在项目根目录创建 jsconfig.json，配置 paths， 让 VSCode 能识别 @ 别名并支持 Ctrl+点击 跳转。 
// jsconfig.json（根目录）
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["src/*"]
    }
  },
  "exclude": ["node_modules", "dist"]
}
